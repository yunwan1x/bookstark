## 还原规则

- 页面外壳、导航、任务面板、工具栏、画布安全区、悬浮工具、状态栏和移动任务面板以原型几何为准。
- 原型中的照片、共享文档和可变业务文本在视觉比较时使用固定 fixture，并对媒体画面内容做 mask；不能用生成图片里的虚构业务内容替换真实功能。
- `07-mobile-annotation-chat.png` 在评审时拆成左右两个独立状态，不把双机展示板实现成实际页面。
- 生成图中的偶发文字误差只校正为现有功能的真实中文文案；不得为了像素对齐引入不存在的功能或重复入口。
- 桌面和移动端共用设计 token 与功能状态，不维护两套互相漂移的业务 DOM。
