# 01 青蓝航空 HUD — 实现与复核记录

## 设计基准

采用 `artifacts/cyan-hud-all-pages/` 的 01–44 设计图，沿用现有页面功能和真实数据。
复核重点：近黑深蓝底、青蓝/冰白细线、固定尺寸切角、角标、页边刻度、角形 Tab、选中态、容器留白及不透明浮层。
设计稿中的示例文案、记录数量、时间及生成图附带的装饰文字不替换业务数据；认证页保留真实的独立登录流程。
不把这些动态内容差异计为像素级一致，也不声称生成图与真实网页逐像素相同。

## 实现

- 个人设置新增中英双语「青蓝航空 HUD / Cyan Aviation HUD」，独立于现有四种主题。
- 七个首屏入口同步注册深色方案，避免刷新和编辑器入口回退；沿用主题存储与跨标签同步。
- SVG 九宫格边框保证切角不随面板大小变形，不用裁切父容器的方式绘制边缘，避免弹出菜单被截断。
- 首页「我的内容」拥有完整分组外框，默认展开；最近访问、日历及快捷导航独立成框。
- 专题 Tab/操作按钮留出内边距，窄屏自动换行；评论区有完整外框，详情不再重复套框。
- 对话框、AI 面板、菜单、手机抽屉使用不透明背景；书签滑动前景遮住操作托盘。
- 广场搜索维持单框；书签公共列表不重复嵌套装饰框。
- 书籍、编辑器、管理页、电视工作区、图表与认证页统一主题颜色。
- 三个既有白名单 HTML 分享页采用可撤销的样式注入，不修改数据库中保存的 HTML 或 WebRTC 交互逻辑。

## 设计复核修正

1. 缩短最初过长的青色边线，改为固定角部强调；增强冰白边缘。
2. 调整标题、首页数字、最近访问卡片与正文大小，修正内容分组与间距。
3. 补齐切角 Tab、书签条目、待办卡片、回收站条目、电视按钮和图表颜色。
4. 去掉专题详情冗余内框，补齐右侧评论完整边界。
5. 检查浮层和书签移动前景的不透明度、320px–1440px 内容边界。
6. 英文 1024px 复测发现导航装饰标识及日历图例拥挤：收缩/隐藏装饰标识，图例自动换行后复测通过。

## 验证

- Chromium：实际本地应用登录、设置主题、刷新保持、首页排序、笔记 Tab；320/390/768/1024/1440px，中文/英文服务端模板。
- `hud_theme_browser_test.cjs`：首屏深色、刷新保持、跨标签同步、AI/书签遮挡、焦点可见、白名单 iframe 启停和任意用户 HTML 不注入。
- `glass_theme_browser_test.cjs`：原玻璃主题与回切保持正常。
- `mobile_swipe_tabs_browser_test.cjs`：鼠标、触摸、滑动和键盘 Tab 操作。
- `theme_chart_lifecycle_browser_test.cjs`：切换主题图表生命周期。
- Go 主题注册、首屏入口、后台 AI 与编辑器主题相关测试；`git diff --check`。
- 40 个桌面页面/状态 + 4 个手机页面截图，初查无页面横向溢出。截图与 manifest 位于 `artifacts/hud-implementation/`，不提交私人业务截图到仓库。
