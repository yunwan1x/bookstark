# 广场本机创作工具

广场右侧提供 Markdown、富文档、电子表格、画板、思维导图、演示文稿六个入口。HTML 不在此工具区。入口新标签页打开 `/tools?type=...`，不打断广场电台；最近两份草稿可直接继续。

## 保存与管理

- 无需登录。所有草稿属于当前站点、当前浏览器配置文件，账户切换不会把草稿上传或同步。
- IndexedDB 数据库 `bookstark-local-tools` 版本 1；`drafts` 保存元数据和更新时间索引，`contents` 保存编辑内容及内嵌图片。侧栏查询仅加载元数据。
- 编辑后自动保存，Ctrl/Cmd+S 立即提交。同一草稿更新同一条记录，没有逐次编辑历史。只有事务成功后才显示“已保存到本机”。
- 草稿支持新建、重命名、删除。清除网站数据会删除草稿；换浏览器/设备不自动同步，用户可导出可编辑草稿，再导入继续。
- revision 在同一个读写事务中比较，多标签页冲突或删除后旧页面保存会被拒绝。冲突内容可导出或“另存副本”。写入失败可重试，离开未保存页面会提示。
- 不自动删除用户草稿。管理列表显示当前使用量；浏览器配额不足时显示未保存，保留内存内容供导出。
- 本机模式图片通过 FileReader 内嵌，Markdown/富文档/表格/演示文稿不调用上传 API；画板跳过上传桥。原有文章、书籍、分享编辑器的保存上传流程不变。

## 导出

所有类型支持 `.bookstark.json`（带 schema、version、type、title、content），并能导入为一份新草稿。导入上限 30 MB，仅接受六种支持的类型及相应结构。

- Markdown：`.md`
- 富文档：`.txt`、编辑器打印/PDF
- 电子表格：当前工作表 CSV；完整工作簿用可编辑草稿导出
- 画板：`.excalidraw`；原编辑器菜单也有图片导出
- 思维导图：PNG、SVG
- 演示文稿：完整可编辑草稿；PPTist 自带的导出菜单保持可用

工具外壳复用现有翻译、主题变量、对话框和按钮组件；窄屏草稿栏为可收起面板。
