# Prompt Studio 单页工具产品规范

## 产品目标

Prompt Studio 用于把零散提示词整理成可复用、可测试、可评估、可发布的版本化资产。工具必须离线可用、无需构建、单个 HTML 即可运行，并在桌面和手机上保持完整工作流。

## 核心对象

每条 Prompt 包含：

- 基础信息：标题、目的、文件夹、标签、收藏状态、适用模型、任务类型。
- 模板：支持 `{{variable}}` 变量语法的提示词正文。
- 变量：名称、说明、类型、默认值、必填状态。
- 版本：版本号、模板快照、变量快照、变更说明、创建时间。
- 测试：测试输入、渲染结果、可选模型输出、运行时间。
- 评估：清晰度、相关性、约束完整度、格式规范度和总分。
- 发布：草稿、可用、已发布三种状态。

## 交互模型

### 桌面

- 顶栏：全局搜索、导入、导出、新建 Prompt、主题和设置。
- 左侧窄栏：只承担收藏、最近使用、文件夹和标签筛选，不承载 Prompt 内容列表。
- 中心主区：完整展示 Prompt 资产列表，提供全文搜索、排序、状态、评分、版本和更新时间等扫描信息。
- 点击 Prompt 后打开右侧无模态工作抽屉；列表仍保持可见并退化为标题清单，允许直接切换下一条 Prompt。
- 工作抽屉使用“编辑、变量、测试、版本”四个任务页签，避免把所有操作永久堆在首页。
- 关闭抽屉后列表恢复全部宽度；新建 Prompt 完成后直接进入编辑抽屉。

### 小屏

- 默认只显示 Prompt 列表；筛选器通过左侧临时面板打开，避免长期占用屏幕。
- 点击 Prompt 后打开全屏工作页，并使用“编辑、变量、测试、版本”四个任务页签，不缩放桌面抽屉。
- 返回按钮始终位于工作页左上角，关闭后回到原列表和筛选位置。
- 标题栏、任务页签和主要动作保持固定；编辑器、变量和测试内容独立滚动。

## 业务流程

1. **Capture 捕获**：新建或导入 Prompt，填写标题、目的、文件夹和标签。
2. **Structure 结构化**：编辑模板，自动识别变量，补齐变量说明、默认值和必填规则。
3. **Test 测试**：填写测试输入，渲染最终 Prompt；默认离线预览，也可调用用户配置的 OpenAI-compatible 接口。
4. **Evaluate 评估**：运行本地规则检查，生成四维评分和改进建议；用户可手动调整评分并保存结果。
5. **Publish 发布**：创建版本、标记可用或已发布，复制模板/渲染文本，导出单条 Markdown 或完整 JSON。

## 产品级辅助流程

- 模板检查：识别未定义变量、未填写必填值、重复变量、缺少目的/约束/输出格式等问题。
- 版本管理：保存前自动快照；支持切换、对比和恢复旧版本。
- 测试样例：每条 Prompt 保存最近测试输入和输出，切换 Prompt 后恢复。
- 评估闭环：每次测试后重算评分，评分变化写入版本历史。
- 数据安全：业务数据默认保存到 `localStorage`；API Key 只保存在当前页面内存，不写入本地、不参与导出。
- 导入策略：支持替换全部或按 ID 合并；导入前校验格式并显示结果。
- 导出策略：完整 JSON 备份包含所有 Prompt、版本和评估；单条 Markdown 便于分享和审阅。

## 验收范围

- 单文件、无外部依赖、可直接通过 `file://` 打开。
- 支持新增、编辑、复制、删除、收藏、搜索、过滤和版本恢复。
- 支持变量自动识别、测试渲染、本地评估、复制和导出。
- 支持完整 JSON 导入/导出和单条 Markdown 导出。
- 支持亮/暗主题及桌面、小屏布局。
- 页面刷新后数据恢复；首次打开提供可操作示例数据和简短引导。
