# 36 公开页面标签：实现前设计
2026-11-07，内置imagegen原型V2及生成/定向修改提示词已保存。V1错误地泛指所有密码保护内容均不计入，已纠正且不用于实现；models/public_feed.go只对文章/笔记明确排除密码，书籍按分享存在条件统计，不在本阶段改Go筛选规则。V2说明以服务器公开页面规则为准，不虚构统计接口或私密标签计数。

场景chips文章/笔记/书籍/书签，对应四个 public_feed_tags_article/note/book/bookmark。浅蓝展示方式卡含auto/manual单选，手动标签按行输入、保序，底部保存当前所有dirty场景。高级原始配置可展开查看与编辑原始JSON；正常编辑保留对象中未知字段，未编辑原始字符串字节不改写。无可用JSON时显示原文和错误，不能静默替换成空auto配置；只有明确选择新配置并确认替换才创建。缺失字段显示未配置。

Go ValidatePublicTagConfig 要求UTF8原始JSON<=32000字节、mode为auto/manual、labels最多100、每项非空/<=200字节/不重复，空值本身不是合法JSON。labels可null或缺失时Go将视为nil，未编辑时保留，修改标签后写实际数组。手动编辑不随意Trim标签（空格可能有意义）；输入末尾换行可作为编辑器终止符，但中间空行要定位提示，不能无声去重/丢项。未知对象字段深层保留，回读显示服务器当前配置，未知结果不自动PUT。

320dp/200%字体chips换行、单选说明纵向增长、多行输入与底部保存可达，至少48dp目标。fresh核权/session、取消/迟到隔离、保存冻结、离开屏障同36。自动模式服务端最多显示热门10项，手动最终只展示server available集合内的标签，UI不承诺所有手工名字都会出现。

需JSON未知字段/原文/UTF8/空行/重复/100项边界/场景隔离fakeHTTP与控制器，窄屏widget，隔离Go真实SQL和NAS redroid。图片和文档不构成功能验收。
