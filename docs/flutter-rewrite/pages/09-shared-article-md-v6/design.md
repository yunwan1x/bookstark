## 分类与权限

PublicEditSnapshot 必须保留来自已核实 PublicShareDetail 的 blogType；目前 parse 丢失该字段。明确 article 的 Markdown 编辑必须进入 WebView；明确 note 保留普通原生笔记；旧服务缺分类时以共享编辑兼容模式进入同一 WebView，不伪造文章/笔记ID。书籍整本、其它格式继续既有独立分流，不假设可编辑。重新读取时分类、目标、kind、保护状态或格式变化必须阻断旧编辑上下文。

编辑链接、token和阅读密码始终在 Dart 权限层，不传入渲染器。新建独立匿名可编辑 Markdown 用途和 Native factory，与只读 public factory 分开；只读 factory 不能通过 JS/options 降级成可写。匿名编辑用途只接收当前租约、规范化服务器和 typed Markdown，支持保存请求/输入锁/快照确认，但不增加账户网络权限。它与已验证 v5 只读阅读共享匿名资源策略：GET、无Cookie/Authorization、无重定向、32条、5MiB单条/20MiB总量、部署前缀/根别名映射及退休取消。URI不含账号、口令或查询参数；公开文本4MiB加载边界保留。

共享编辑保存继续遵守既有500KiB上限、Unicode校验、真实 GET/PUT 接口与权限；不能把大文档截断。超限仅阻止保存并保留本次内容，清楚提示限制。renderer 禁止账户API/file/content、表单/任意网络、任意Native调用。C3已验证的不透明预览、MathJax启动屏障、带nonce/epoch的链接意图与Native用户激活检查继续保留。

## 保存与生命周期

保留 PublicEditController 的 receipt / verified-read 区别。保存先捕获并锁定确切源文档，再 fresh-read；远端等于本次内容则核实成功，不再 PUT。基线变化进入冲突，明确对比后才允许采用远端或再次核对后覆盖。服务端没有原子CAS保证，UI必须如原型提示同时修改仍可能冲突，不能声称彻底防并发覆盖。PUT响应未知只允许核对；有回执但读失败保留回执，仅补 GET，绝不自动重发。已核实状态才能显示“远端已核实”。

沿用本页既有会话内隐私模型：本次内容捕获到当前 Dart 会话内存，不把 token、阅读密码或本次正文写入JS持久存储。暂停图“已保留”表示当前会话，不承诺进程终止后恢复；退出有未保存/未知结果时明确提示并可复制本次内容。原编辑链接页的原生验证/解锁仍是唯一入口，进程重启重新验证。

输入变化、复制、保存、附件插入、冲突对比和离开都使用同一 working-copy / generation / revision。后台、连接替换、外链和离开前捕获最新可读取内容并退休确切租约；捕获失败不能误报保留或悄悄丢弃，保留上次有效快照并提供重试/明确退出。返回显示暂停，不自动创建旧权限运行时；重新核对真实权限和上下文后才能继续，变化时只读保留本次内容。稳定正文父节点避免状态提示导致活跃编辑器重挂载。

## 附件与验证

附件前记录原文与选择范围、锁定来源；原生选择器返回后再次核对会话、当前权限与原文，才按原选择范围插入Markdown。取消不改变原文；上下文或正文变化时保留上传结果供复制，不插入另一篇文档。WebView不接收原生路径/账户客户端。BOM、CRLF、有序标签与未知字段保留；preview不是服务器保存证明。

验证必须包含：分类保留/变化、明确note回归、真实CM6输入与撤销/预览、快照/光标/附件取消、500KiB边界、未知/回执未核实/冲突不重放、后台与外链退休/暂停、原生密码、真实Go共享编辑与精确原文、原数据恢复。先宿主与真实Go引擎浏览器回归，冻结后仅用flutter_app/build.py构建ARM64，在NAS redroid实际验证。当前v6尚未实现或验收，全部45组仍未完成，固定26不变。
