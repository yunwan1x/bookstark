# 21 网盘文件原生预览：实施前契约

21-file-preview.png在UI代码前生成。白色AppBar返回/文件名/分享/更多；面包屑；原生预览主体；格式所需真实控制；文件信息卡；保存到设备/分享文件。PDF原型的12页/2.4MB均示例，实际使用解码后的真实页数、仓库字节数、真实公开状态，禁止固定假页码。图片使用NativeImage+缩放，SVG保留安全限制；PDF使用原生PDFium组件；音视频使用原生音视频插件与生命周期，不用iframe、HTML媒体或WebView。不能解码、需要密码、失去权限、文件已删除/更换、下载失败、格式不支持各自有明确状态和实际重试/下载。

选型依据已查官方包文档：pdfrx 2.11.0 https://pub.dev/packages/pdfrx （Flutter3.47/Dart3.13，Android原生assets PDFium，2.5后使用独立material_ui主题与本地化）；video_player2.14.1 https://pub.dev/packages/video_player （Android SDK24+，原生ExoPlayer，Web不支持file构造）。依赖尚未加入；须本项目NAS工具链解析成功、构建、真实解码验证后再定版本。音频复用已锁定just_audio，避免无意升级听书依赖。PDF链接/外部动作只在用户明确操作时处理，不自动执行未知脚本/加载外部资源；密码仅当前会话，不写日志或默认持久保存。

私有文件只能同源认证读取，不把Cookie拼进地址、不交给会跟随外站重定向的组件。大文件下载使用有界分块、反压、取消；字节本身无损。若媒体通过临时文件预览，明确已实际缓存到应用临时目录并清理，不能冒称流式；若采用回环Range代理，则服务器仅127.0.0.1、不可猜测路径、只代理当前已认证源、会话关闭中止上游、转发真实Range/Content-Range/ETag/Length，不将认证暴露局域网。没有验证的模式不声明支持。TTS14流式链路保持原实现，网盘预览不覆盖其会话/音频焦点。

PDF页码、上一页/下一页与缩放均绑定真实控制器；首尾页合理禁用，密码取消不显示空白成功。音视频播放/暂停/定位/时长取实际播放器状态，不能用计时器假进度；离页暂停并释放播放器。图文预览仍保留实际文件信息/公开状态。保存到设备要走系统文件位置选择并核对写完，分享只交付实际完成的原文件；取消不提示保存成功。下载失败清理不完整文件，不误删用户已选目录中的原文件，覆盖须确认。缓存清理/重启遗留属于45验证门槛。

测试包含真实PDF页/密码/错误、GIF多帧、实际音视频解码与定位、Range/取消/无凭据外泄、系统保存与分享、小屏/大字体/键盘、真实Go与Android。浏览器fixture只能证明渲染/交互，不冒充原生解码或真机验收。设计中，未实现。
