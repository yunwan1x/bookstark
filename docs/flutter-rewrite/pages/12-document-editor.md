# 12 Markdown文档编辑（实施前设计）

参考12-document-editor.png：顶部返回、标题和保存；真实书籍/父章节路径；名称输入；编辑/预览切换；共享Markdown工具；正文；草稿提示。原生TextField和现有BookstarkMarkdown，不新造渲染器。附件沿用现有选文件、上传、私有下载鉴权、图片缩放与系统分享链路。每个按钮中英文和48dp触控目标，小屏两倍字体下工具栏换行、整页滚动。

文档已通过目录创建并取得真实ID，编辑器只更新该ID。名称与正文分别提交，正文用单独 {markdown: ...} 避免旧Go接口忽略空正文。分别记录已成功的名称/正文，不把部分成功说成全部失败，也不覆盖保存请求之后继续输入的内容。保存后重读验证；重试继续原ID。非Markdown类型不进入此编辑器。

名称200 UTF-8字节、正文500000字节；输入超限保留并说明。草稿使用当前服务器/成员命名空间和文档ID的安全存储；恢复需用户选择，损坏读失败明确处理，删除失败不静默离开。返回提供继续、保留草稿、放弃。自动保存和生命周期持久化作为后续回归范围，不以明文降级。

回归：空正文真实清空、重命名不改正文、部分成功与请求期间输入、草稿恢复/清理失败、附件流程、320dp英文200%键盘、真实Go与本地SQLite、浏览器截图/真机。
