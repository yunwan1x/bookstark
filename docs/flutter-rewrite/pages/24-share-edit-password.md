# 24 受保护共享编辑的密码验证：实现前原型

2026-11-05。先生成24-share-edit-password.png并发送。复用解锁表单结构但有独立文案/原型：AppBar验证分享密码，受保护编辑说明与真实标题、密码显隐字段、仅本次编辑会话提示、验证并编辑，权限信息卡和返回阅读。不能沿用普通解锁“仍为只读”的文案误导已有合法编辑能力的用户。

进入前已GET token edit验证能力，只有Markdown且has_password=true才请求密码；无效编辑token不先询问密码。密码原样提交公共verify-password验证后再提供正文，旧token后期添加密码的资源仍需在每次保存PUT带实际密码。仅当前编辑控制器持有内存密码，不入路由URL/日志/安全存储/草稿/剪贴板。失败受限通用文案，不回显输入；取消触发当前有界HTTP请求中止，回阅读不做PUT。

可复用ShareUnlockPage的表单与超时/取消逻辑，但普通阅读默认行为和文案保持原意，编辑变体需通过单独回归。校验正文/类型/保护状态，不能把服务GET的空正文当可编辑空文件。保存时仍复核权限/版本，密码解锁不会授予其他资源编辑权限。原型锁图形可用同体系MaterialIcons组合，布局16dp白卡、淡灰蓝背景、320dp200%和键盘可整体滚动。
