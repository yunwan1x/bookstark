# 10 待办编辑补充设计（实现前）

原型 `10-task-editor.png`，内置imagegen，提示词同名prompt.txt。原生返回/编辑待办/保存AppBar；16dp滚动表单，状态提示、待办正文多行边框输入、计数、B/列表/勾选格式按钮与预览、截止日期、已完成、父待办和离开提示。色彩/圆角/字阶来自AppTheme，格式操作和原生Markdown预览复用08能力，不再造另一套Markdown语法或WebView。

- 原型49/1000是排版样例，运行时必须按实际content.runes.length计数，不能硬编码。服务端最多1000 Unicode码点，空白内容不提交，输入不截断emoji。Markdown格式插入后也重新计数。
- 新建根/子任务标题相应变化，子任务的parent_id来自真实父任务。编辑已有任务先GET完整详情；父关联和专题关联不能在保存正文时被置零。
- 日期通过原生日期选择器修改，保存YYYY-MM-DD。默认七天后仅在新建/旧记录空日期时明确展示；编辑有效既有日期保持原值，不自动“刷新”为七天后。修改说明不能伪称原任务已经变化。
- 保存禁重复，完成后才更新已保存快照；请求进行中编辑的新内容保持dirty，不用旧快照覆盖。失败保持输入/日期/状态，可重试。提交中不能重复返回/销毁保存结果。
- 保留草稿使用安全存储和串行写入，根任务/各父任务的新建草稿隔离。恢复须选择，损坏/写失败可见；保存/丢弃清除的顺序不能让旧延时写复活。
- 系统返回/上方返回/离开空间统一dirty确认：保存、保留草稿并离开、丢弃、取消。保持日期和完成状态不只正文；不得静默丢输入。
- 预览用共享BookstarkMarkdown，链接按相同owner规则弹确认/原生附件，不把任意文本当可执行URL。小屏键盘/200%文字整个表单可滚动，保存动作始终在AppBar。

与10主设计联合验收；独立截图不能替代真实Go/SQLite保存和Android系统返回回归。
