# 08 Markdown 笔记编辑与预览

原型 `08-editor.png`。原生返回/保存栏、空间与草稿状态、标题、标签、编辑/预览切换、大段文本编辑区、格式工具栏、真实附件列表、阅读入口与溢出菜单。所有状态文案必须以实际保存结果为准。

Repository按空间处理：本地SQLite；服务器新增 POST `/api/blogs`，修改 PUT `/api/blogs/:id`，字段遵循现有 `blog_title/blog_content/blog_type/editor_type/labels`。读详情 GET `/api/blogs/:id`；标签用 `/api/labels/resource/blog/:id`，避免读不到标签后保存时误清空。

格式：标题、加粗、斜体、待办、链接、图片插入保持光标与选区；预览复用Flutter Markdown组件，支持标题、列表、代码、引用、表格、链接和图片。远程资源和附件必须经过当前空间的解析规则，不能把Cookie发送给任意图片域名。

草稿以空间+文档ID隔离保存；保存中发生的新输入不能被旧响应当成已保存。保存失败保留正文，离开时可保存/保留草稿/取消。受密码保护的正文默认只在内存保留，不将解锁密码或明文草稿写入普通SQLite。解锁取消时不允许保存空内容。原有加密协议不得绕过。

附件需要真实Android文件选择/拍照（如已有权限能力）、持久附件目录或服务器上传、图片预览与系统分享；不能只用原型中的附件占位。当前阶段尚未宣称附件/加密/全部格式回归完成。

验收：真实本地/服务器创建→保存→返回→重开；弱网失败、保存时继续编辑、草稿恢复、密码保护；链接/图片/代码/表格；键盘、选区、返回、中文英文和字体缩放；截图对照。当前：原生编辑器实现中，见下方实际进度。

## 草稿与解锁补充实现

`08-drafts-unlock.md`、`08-unlock.png`、`08-draft-recovery.png` 在实现前补齐。Android实际入口使用FlutterSecureStorage保存非保护笔记草稿，按本地/规范服务器+已认证服务端用户ID+文档ID/新建槽隔离。600ms防抖、生命周期暂停排队保留、离开选择保存/保留/放弃/取消；存储失败保留文本并明确提示。密码笔记不读取/写入磁盘草稿；密码仅在当前编辑器Note对象中，关闭不缓存，每次重开重新解锁。保存沿用password字段，禁止用会清除保护的current_password字段。

服务器的普通Blog PUT忽略空标签、且未上抛标签绑定错误，故保存后使用PUT `/api/labels/resource/blog/:id`确认替换；新建已成功而标签失败时返回NoteSaveFailure(savedId)，编辑器保留ID及未完成状态，下一次保存更新该ID，不重复创建。新建空标题生成可见名称；已有标题不允许清空后虚假显示保存成功。

视觉回归使用独立 `./build.py --visual` fixture入口，其数据不进入生产 `lib/main.dart`；390×844浏览器输出5张实际Flutter截图。已人工查看编辑、Markdown预览与原型的关系，仍有附件区、状态栏、页内间距和部分功能/视觉细节未齐，不能声称完整逐像素还原。320dp、2倍英文+200dp键盘导致的溢出先由测试复现，再改为可滚动头部与自适应切换按钮，通过回归。

当前37项自动测试和静态检查通过，包含解锁协议、错误密码无PUT、草稿隔离/队列/失败/重开、密码内容不持久化、保留并离开后恢复、标签清空与部分失败防重复新建。浏览器测试验证路由/弹窗/切换和零页面异常，Markdown文字/排版同时人工截图核对；这些不等同于真实Android设备、真实远程服务器写入或旧库迁移验收。
