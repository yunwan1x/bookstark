# 11 书籍设置原型

实施前设计。参考同目录 11-book-settings.png；新增书籍复用同一表单，标题为“新建书籍”，不显示现有文档数量。

白色顶部返回、18sp 标题、保存；16dp 内容边距。依次为书名、四行说明、可删除标签、添加标签及已有文档数。复用应用主题、原生输入框和共享标签组件。中英文文案适配，小屏、大字体和键盘出现时整页可滚动。

书名最多 200 UTF-8 字节，说明最多 2000 字节；前端准确说明字节限制。保存前读取详情的真实标签，不从列表 CSV 猜测。保留旧标签空白；旧 API 无法无损表示含逗号的单个标签时先阻止保存并说明，不先修改正文。创建后标签同步失败保留已创建 ID，重试更新，避免重复创建。

未保存返回提供继续编辑、保留草稿、放弃选择。保存期间禁止重复提交；异步保存不能覆盖请求之后输入的新内容。文档数只读，不编辑内部标识、排序或封面。删除位于列表菜单，明确删除书籍及全部文档和分享，不承诺后端未保证的恢复能力。

验证：真实接口与本地存储、重名、字节上限、标签清空及同步失败、返回草稿、320dp 英文两倍字体键盘、原型截图比对。真实 Android 验收仍需设备。
