# 44 · 旧版内容格式确认 V4
使用 imagegen 内置图像工具生成的六状态原型，生成并归档后才开始本页实现。
图：44-legacy-format-v4.png；完整生成提示词：prompt.txt。
原型为真实选择/预览流程的视觉依据，不代表旧版迁移已接入。

## 页面与状态
1. 未选择：每个旧版笔记/文章必须明确选择格式；无默认 Markdown。显示原始标题的只读展示，不把显示用“未命名”写回数据。
2. 选择：七种格式 Markdown、HTML网页、表格、画板、思维导图、富文档、演示文稿；点击确认后仅修改该项的迁移配方，不修改原文或已选其它项。
3. 批量：只应用于尚未选择的项，明确显示数量；不能覆盖用户已有选择。不提供可取消这一限制的开关。
4. 核对：全部明确选择后可提交格式配方；用户仍可改选。它只返回选择结果，不能触发恢复、数据库写入或激活。
5. 原密码预览：可选，不是导入的解密或取消保护操作。使用已验证的临时加密通道，验证原 bcrypt 并解密 ENC正文。错误显示固定本地化消息，绝不回显原生错误详情、哈希或密码。
6. 原文片段：纯文本转义只读片段，最多2048 Unicode字符；不执行 HTML、脚本、公式或文档引擎。可选择格式后返回。保留原始受保护数据与哈希；不把解密正文存入配方、SQL、偏好或草稿。

## 视觉与响应
参考390dp宽；16dp横边距，12/16dp间隔，白背景，#0C192E正文，#0050F5主色，浅蓝信息卡、灰色描边卡。
AppBar 56dp、标题20sp/700，正文16sp，辅助14sp。卡片12dp圆角；按钮最小48dp高并随大字体增长。采用现有 LocalBackupScaffold 的单滚动视图，短页动作靠底，长页动作可滚到；不能用溢出或裁剪保持截图。
选择底表自适应高度并可滚动，七项始终可达；320dp/200%及英文必须回归。
以原型与逻辑尺寸逐状态对照，不以自行生成golden声称已证明与AI原型逐像素一致。

## 配方与范围
配方绑定原归档SHA256和稳定的源标识；编辑器字符串使用现有引擎真实类型，展示名称本地化。
文章仍遵守用户整模块WebView要求，底层内容格式选择不改变文章模块架构。
来自旧书籍章节的已知doc_type不在本页批量覆盖范围内。未知格式/重复或缺失标识不自动降级。
输入源是已检查、持有生命周期的私有暂存对象；变更来源必须新建本页状态，旧选择与密码预览均失效。

## 生命周期
密码字段不建议自动填充/建议，保持遮罩；预览弹层/页面关闭、应用后台、路由退休时取消进行中的解锁并清空密码/片段引用。
迟到结果必须检查源与页面作用域，不能重新打开预览或覆盖已选择格式。
只有显式点击重试才再次计算。等待解锁不锁死整个App；返回可以取消，不自动恢复任务。
保护窗口使用既有安全窗口能力；浏览器视觉fixture不冒充Android密码保护/安全窗口证明。
