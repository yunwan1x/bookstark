# 17 主题评论（实施前设计）

原型17-comments.png。全主题评论列表/实际目标过滤，显示来源目标、小结/资料/任务标签、作者/时间、原生Markdown、编辑/删除菜单和真实分页；添加先选择当前主题内真实目标，再进入共享正文编辑器。没有topic根评论写接口，也不提供回复层级；GET不传target可查全主题，不能据此创建无目标评论。scope严格owner，作者来自真实API，本地空间明确本地作者。

创建target_type仅resource/summary/task，target_id分别是资料关联ID、小结ID、任务ID，不是资料源对象ID。编辑只改正文、不能变更目标。20000码点与请求256KiB限制，安全草稿按空间/topic/type/target隔离；复用Markdown预览与附件能力。评论编辑子页须另出原型后实现。

删除明确确认，失败保留内容/分页，成功回读真实计数；删除小结/资料后相应评论目标失效，不允许跳到其他资源。现有旧回复由Go转换成一级展示，不凭原parent_comment_id建立未支持的回复树。无数据、无目标、404、权限/网络错误状态可辨。中英320dp/200%字/键盘/分页与草稿回归。当前先设计，UI尚未实现。
