# 09 Local article Markdown WebView v1
Prototype: 09-local-article-markdown-v1.png; built-in imagegen ui-mockup; prompt.txt. Saved before implementation.
Four existing-article states: saved, editing, preview and explicit old native-draft adoption. Native shell retains return/title/save/local status; toolbar, Markdown source and preview are WebView bodies. Ordinary note Markdown remains native. Existing HTML and five JSON editors remain on their current tested WebView/recovery paths.
Use the existing bundled Go CMHtml CodeMirror6 engine with its Markdown extension, line numbers/history, and formatting toolbar. Do not treat Markdown as HTML or JSON, or save it through the HTML update API. Add a typed Markdown document kind with explicit 20MiB byte budget, strict Unicode/exact original source identity and unchanged BOM/CRLF preservation. Bounds are explicit failures, never truncation. Larger legacy records require separate bounded/read-only work before full page completion.
Preview must be in an opaque sandboxed iframe with no parent native bridge. Reuse bundled Go Markdown rendering; allow pinned static assets only. Do not place untrusted rendered Markdown HTML in the main bridge-bearing frame, whose existing CSP permits unsafe-inline. Bind frame messages to its exact contentWindow, random generation nonce and bounded typed fields; reject forged/retired messages. Network, file/content access, cookies/storage and unsolicited permission/upload remain unavailable. Preview does not mark the source saved.
Existing local article routes must validate current store/generation, collection=article, editor_type=markdown and positive ID before body reads. Metadata/source/title/labels must use the current transaction/fingerprint protections. No editor-type conversion or schema bump for a UI route. Ordinary local Markdown notes must still open native NoteEditorPage.
Old article DraftVault namespace must remain recognized. Compare saved/draft fields, never silently discard. A visible explicit restore choice copies the chosen draft into the new durable recovery before editor handoff. A metadata-only digest marker may archive an explicitly handled old draft without deleting its original bytes; an explicit recovery-manager entry must still be able to review it. Do not mark a draft handled before durable transfer/choice, overwrite another complex recovery, or resurrect an already saved old draft. Pending/uncertain commits must use existing review, fresh-read and cleanup barriers; no automatic replay.
Initial scope is existing unprotected primary-store articles. New article creation, old unsaved new-article drafts, protected schema15 editing, attachments and public/anonymous variants remain required follow-up work; do not mark 09/all45 complete after this increment or expose fake successful controls. Preserve all45 objective.
Verification: typed kind and exact bytes; malformed Unicode/limits; current generation/collection boundaries; real Go CM6 input/snapshot and Markdown preview DOM; hostile Markdown HTML cannot access parent bridge/network/files; formatting/undo/preview retains source; old draft restore/skip/failure/restart retains both sources; actual local SQL save/reopen and source12/14 upgrades/data restoration; ARM64-only build/NAS redroid. Native return/external handoff must checkpoint and retire first.
