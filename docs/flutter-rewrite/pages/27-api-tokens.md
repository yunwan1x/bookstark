## 真实接口

GET /api/api-tokens -> 当前账户token_id、member_id、masked_token、name、create_time数组。服务不会返回完整token，禁止编造已有令牌复制/查看。最多100条、按ID升序；没有总数和分页信息，不能标“共100条”。POST同路径 JSON{name}，UTF8字节不超过100（虽然服务提示字符），空字符串服务取default，不按字符长度误判。返回data内再包含data令牌元信息和token完整64位十六进制秘密。完整令牌仅保留在当前一次性结果内存，明确显示/复制，离开清除，不写草稿、日志或列表缓存。

DELETE /api/api-tokens/:id -> code/message回执。服务不返回受影响行数，先绑定真实当前账户及已读ID，再以实际列表核对；限额100条时，超出返回范围的ID不能用“列表不存在”断言删除成功。创建成功后ID超出100条应保留本次真实结果卡，解释列表截断，并允许依实际创建回执对该ID明确撤销。

## 未知结果与确认

创建/撤销均不自动重试。创建请求未知后刷新只能读到掩码，不能恢复完整秘密，不能把唯一新行当作本次创建的充分证明。撤销确认文案带实际名称与ID，解释工具访问会失效。未知写入保留状态和只读刷新，不自动重复创建/删除。普通刷新不进行任何写入。原服务没有到期时间、上次使用、可选权限范围；界面不臆造。

## 验证计划

仓库字节/身份/字段/列表上限，控制器未知写入，原生确认、一次性结果和离开清理、英文320dp/200%，真实Go创建/撤销/100条截断和API鉴权缓存失效，Android实际操作与保留本地数据。仅隔离账户创建测试令牌，不输出真实令牌。当前为协议和原型阶段，尚未实现。
