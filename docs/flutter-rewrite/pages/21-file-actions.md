# 21 文件操作与路径对话框：实施前契约

原型21-file-actions.png在UI前生成：实际文件名/大小/公开状态、48dp操作网格、永久删除红色按钮、不可从回收站恢复提示、取消。窄屏或200%字体改为单列可滚动，背景目录保持当前滚动。目录只显示实际支持的进入/重命名/移动/复制/永久删除；文件的预览/编辑依实际类型展示，不能把无效入口列出来。取消和背景关闭不触发任何写请求。

重命名保留父目录并只输入真实单文件名；移动/复制选择真实目录并允许目标文件名，面包屑逐层进入，禁止自身及子目录。新目录先填写有效名称、明确确认后POST，成功取实际ID。名称Unicode/%/空格保留，禁止控制/斜线/..，冲突显示真实服务端错误，不自动覆盖或造成功。读取目标权限失败不当目标不存在。

永久删除确认明确对象名和目录全部子内容、不可恢复、可能破坏引用；只在确认后提交。所有写请求串行禁重入，响应未知保留待核对操作（源ID/原路径/目标路径/etag），只读核对失败不重发；目录新建、复制、移动、删除的判断分别核对实际父目录ID和目标，不用名字猜成功。界面离开或空间切换取消尚未提交任务，已提交可能仍完成需说明。公开设置是独立页面，不能在打开操作菜单时调用含写入的检查接口。状态设计中，尚未实现。
