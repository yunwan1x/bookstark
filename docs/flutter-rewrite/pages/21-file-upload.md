# 21 网盘文件上传队列：实施前契约

原型21-file-upload.png已在UI代码前生成。顶部返回/上传文件；真实目标目录卡与可用的目录选择器；同名需确认提示；系统多文件选择；独立队列卡（文件、字节数、状态、移除）；同名冲突的改名/覆盖/跳过；底部开始上传/停止后续项目/返回。图中两个待处理与一个冲突是示例，不作为运行时固定数据。

选择文件、读取元信息、计算SHA256不写服务端。只有开始并明确解决冲突后，才触发上传或含写入的check/prove加速。目标检查使用真实父目录列表，不把upload/check当只读。每行独立ID，同名也不覆盖另一行队列状态；同目录队列之间的同名也需识别，不能只检查原服务端列表。覆盖确认后到提交前再检查基准ID/etag，变化重新询问；旧Go不支持原子If-Match，仍有竞态必须诚实保留门槛。

单项流式SHA/上传，分块进度有节流，避免全部文件同时读内存；服务器单文件上限/配额真实显示，取消后跳过后续。源文件大小/mtime/内容若在读取间变化，不沿用旧hash作已验证结果。超限、不可读、权限/配额拒绝保留该项并继续后续，不自动重试。发送完成仍待服务器确认。响应或停止后结果未知，先按目标实际path/ID/etag核对，只读核对失败不重POST，核对缺失后另行明确重发，告知旧请求可能仍完成。成功/复用说明实际对象、目标路径、是否真实deduplicated，不伪造“新增”。

全局复用：POST check在拥有blob时可立即写目标；跨用户挑战最多3个索引，1MiB块，nonce十六进制；SHA256(nonce原始字节+对应原文件块)，token短时单用。参数边界/当前账号/真实源验证后才prove，失败不隐藏为成功。小于2块且无所有权时回正常上传。队列移除/返回不撤销已提交的远程写请求，离开需说明；进程终止持久恢复归45，未完成不能宣称支持。

测试覆盖系统选择/取消、同名与队列冲突、改名/覆盖/跳过、Hash/proof真实协议、流式边界、源变化、取消、部分失败、无响应核对、真实Go去重/覆盖/权限/配额以及中英小屏大字体。状态实现中：上传队列、上传页与真实目录选择器已实现，6项针对性测试通过；仍需未知结果暂停后续项目加固、持久恢复、完整中英小屏大字体和真实Android/浏览器回归。
