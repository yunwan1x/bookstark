# 21 原生文本文件编辑：实施前契约

原型21-file-editor.png已在页面代码前生成，母规范21-files.md。AppBar关闭/实际文件名/保存；目录相对路径；未保存提示；撤销/重做、编辑/预览切换；原生多行代码区与行号；UTF-8/真实字节数/修改状态。16dp边距、48dp触控、键盘出现编辑区滚动、状态栏不盖保存。撤销/重做使用真实编辑历史，无历史时合理禁用不是未实现占位。预览Markdown复用现有原生Markdown组件，纯文本原样显示；HTML仅源码，其他受限HTML预览归29，绝不执行脚本或WebView。

严格有界原文件UTF-8解码；非法编码/二进制拒绝编辑并提供真实文件下载/分享。保留原BOM/换行信息，不用Go的string(bytes)当作无损读取保证。空文本可保存为0字节。加载失败不初始化可覆盖的空白编辑器，必须重试成功后才允许保存。未修改可退出，修改后退出确认保存/保留草稿/明确丢弃。草稿按空间+member+路径+稳定节点ID隔离，包含基准etag/原文版本、MIME、修改正文、时间，不把另一用户/另一同名新节点的草稿直接套用。

保存前按实际父目录/ID/路径及etag检查当前服务端对象；对象消失、被移动、更换ID、内容变化分别提示，不盲目覆盖。冲突可比较/重新读取/另存文件或明确覆盖；下载字节计算哈希验证实际基准。旧Go无原子条件保存，预读后仍有并发窗口，不能承诺多端无冲突。响应未知保留稿与本次提交哈希，先只读核对etag再决定，不把网络失败当一定没保存；确认实际保存后再清草稿，草稿清理失败保留真实已保存状态，不重复新建或伪报失败。

保存、预览、复制不输出账号凭据，公开文件编辑需提示现有公开地址会反映新内容。页面切换、空间切换、加载代次必须隔离。测试覆盖UTF-8/BOM/CRLF/空内容、文件类型边界、撤销/重做、基准变化/未知结果核对、真实Go保存与本地原子替换/回滚、草稿恢复、小屏大字体键盘。状态：实现中；FileEditorPage/FileEditorController已实现主要编辑、草稿和保存核对，9项针对性测试通过。尚缺另存、明确丢弃/退出保存分支、二进制下载入口与完整视觉/真机门槛，详见阶段工作记录。
