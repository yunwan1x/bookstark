当前API均在 /api/admin/assets，而非 /api/assets。GET /ssh-hosts只支持q/status；GET /credentials没有搜索或分页参数。两类接口返回数组，没有总览聚合/全局健康率接口；计数只能来自当前成功读取数组，加载/失败不显示假0。凭据页显示名称、用户名、password/key类型及明确配置状态，不显示密码或私钥。主机列表和凭据列表的加载错误单独重试，筛选变化不能伪造全局数量或自动执行连接测试。

现有Go会在返回前解密并填充credential字段，不能声称服务端不会返回秘密。列表解析只保留必要元数据和是否实际收到非空凭据，随即丢弃明文引用；不写入日志、草稿、分析/崩溃事件、截图或客户端磁盘。只有明确查看/修改动作才进入受限秘密生命周期；若未提供明文或明确状态字段，显示“未提供”而不猜测已配置。密码、私钥和资产加密密钥必须默认掩码。Dart字符串只能清理引用，不能声称内存已物理零化。

新增/编辑主机、主机详情/检测、凭据新增/编辑/明确查看、删除确认和资产加密设置都需要各自先补原型与契约后实现。图中按钮最终必须接真实功能，不能加入空回调占位。终端、SSH文件、WebDAV和Docker属于40–43的独立闭环，不能以此总览宣布它们完成。资产设置会涉及凭据重包裹，禁止拿36的两个终端策略保存当作其替代，也禁止因读取总览自动轮换密钥。
