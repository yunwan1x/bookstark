## 视觉及页面
沿用首页24dp边距、12dp白卡、蓝2563eb与Slate文字。三屏为本地模型配置、流式Markdown对话、笔记工具草稿核对。Android窄屏与200%字体整体纵向滚动，表格横向滚动；48dp触控。页内正文复用BookstarkMarkdown，禁止将原始Markdown直接当普通Text显示。文章/复杂内容仍以既有WebView为最终编辑入口。

模型配置页展示当前本地空间，服务地址、模型标识、遮罩密钥与显隐按钮、默认关闭的本地知识检索开关、测试状态、独立测试连接与保存配置。明确“问答内容会发送到你配置的模型服务”“仅加密保存在本机”。允许没有密钥的自建服务，不填默认公共端点，不在打开或修改字段时自动联网。模型连接仅由明确测试/发送触发；未测试也可保存有效配置，测试不可冒充已保存。大字时按钮竖排，字段/错误/键盘可滚动。

对话页区分当前空间/已保存模型与资料检索授权。问题、来源、流式状态、停止和部分回答保留均真实；未完整结束不计入成功轮次。模型/作用域变更必须取消旧连接、隔离会话，不能把服务器Cookie发到模型服务。

草稿核对页完整展示标题、正文或任务/日期，明确“尚未写入本地数据库”。取消不写内容；核对后先打开既有原生草稿编辑器，用户明确保存才创建。直到拿到真实保存回执，AI卡片不得显示已创建或编造ID；普通笔记保持Markdown原生，文章及复杂编辑保持WebView。输入中的“确认”文字不是写入授权。

## 配置和传输契约
兼容现有Go所使用的chat/completions协议，不绑定某一厂商或猜测模型名称。服务基址必须明确HTTP/HTTPS、无userinfo/query/fragment、不能是文件或其它协议，保留用户路径前缀。模型非空且有UTF8长度限制；密钥有长度和控制字符限制，不回显到日志、异常或URL。连接到用户选定地址使用独立无Cookie/CSRF客户端；拒绝跨域及其它重定向，不将模型密钥发到附件/外链/第二主机。端点测试仅用当前表单快照，失败保留草稿，关闭页真实取消。

配置按当前实际数据库身份隔离，用既有默认FlutterSecureStorage显式名称及独立JSON元数据键[bookstark.model-v1,数据库身份]保存，避免污染bookstark.local-*恢复日志清单。密钥留本机，不随本地内容备份导出；不改变原SQLite表或附件。保存由明确按钮触发，任何不确定存储回执都先重新读取核对，不乐观标记保存成功；损坏记录保留并提供确认后仅清此配置的重置。持久化前后核对当前作用域，迟到读取/测试不能覆盖新输入/新库。

本地工具只允许当前库的搜索/按真实类型ID读取，且须先启用本地知识授权；默认不发送任意本地文件、绝对路径、其它空间/账号内容或模型伪造URL。读取带有界结果和正文预算，已删除/保护/编辑类型都要明确处理，不把HTML等源代码伪装普通Markdown。工具输出是数据，不能覆盖宿主规则或自动执行写入。

本地聊天/工具草稿用独立加密会话记录，保存真实轮次、草稿随机身份与状态；停止、后台、重启及失效来源均须可恢复。工具创建最终需要持久化pending和同事务创建回执/已知真实ID，未知结果不重放；在该闭环完备前不宣称本地工具创建完成。不得把后台AI生成或仅保存内容当作真实用户访问记录。

### C 保存事务细化（先于接入编辑器/写工具）
模型提议只支持普通 Markdown 笔记和待办，拒绝 ID/路径/SQL/editor_type 等额外字段。加密草稿清单按 DB+模型绑定隔离，最多6项；pending、committing、unknown、cancelled、created 明确区分。先持久化最终编辑输入的规范摘要并等待原生存储屏障，才允许 SQL。committing/unknown 不接受重复保存或直接取消；必须只读查询真实回执并展示现状，用户审阅后处理。编辑中的完整正文保留在独立 AI 草稿身份下的现有编辑器草稿仓库，不在回执表存正文。
计划后续活动 schema16 增加 assistant_creation_receipts：随机 creation_key、note/task 类型、真实 resource_id、input_hash、created_at。原 schema14 函数保持冻结；新增创建与回执 INSERT 同一事务，失败整体回滚。资源永久删除仍保留回执，旧请求不能复活资源。已有回执仅供只读核对，不能把它当作自动重放成功。采用创建时摘要与当前资源摘要分别核对，资源已修改/删除必须明确展示。激活版本前同步迁移、内容备份/恢复及旧库回归；不复用 HTML 创建回执表。

版本审计补充：旧版导入已有独立候选 schema15，不能把 AI 回执的活动库格式也叫15。活动14与冻结14备份验证器、候选15导入验证器暂不变；回执DDL目前仅在隔离SQL测试中安装。后续16的激活必须同时完成14备份兼容、16导出/恢复，以及旧版候选的升级/合并证明，不能绕过严格结构校验。


### 保存结果核对页（实现前选定原型）
选定图：save-result-review-v1.png；提示词：save-result-review-prompt.json。Flutter 外壳采用白底圆角资料卡、琥珀色待确认提示、底部蓝色操作。找到回执时显示实际资料及只读 Markdown 预览；当前资料已变化、删除、加密或转换格式时明确提示，复杂格式只通过原有 WebView 打开。未找到回执时保留原编辑草稿，不自动重试创建。确认前必须重新读取并比对核对指纹；放弃只结束本次尝试，不删除资料或草稿。大字体采用可滚动单列和可换行操作。

保存回执补充：待办编辑器若已收到确切保存ID，但后续元数据持久化失败，保留编辑正文并把后续操作绑定该ID；显示错误提示。不得把这类失败退回“全新待办”而再次插入。AI恢复入口继续保留原完整草稿。


### 未完成回答的明确替换（实现前交互补充）
沿用本页原型的圆角对话框与既有 Markdown 展示。停止、失败或重启恢复后仍有非空部分回答时，发送新问题先显示可滚动的中英确认框，完整保留原问题和部分回答供核对，明确其尚未完成且不会加入模型上下文。默认操作“返回并保留 / Keep unfinished reply”不发请求、不改变原部分回答、原问题或完整消息；明确“替换并发送 / Replace and send”才替换当前未完成回答并发送该次新问题。一次只开一个确认框；关闭、页面销毁、会话或仓库变更后不能继续发送。窄屏、大字与键盘仍能滚动到两项操作。不改加密存储格式，不把半成品加入完整消息。


### 放弃保存后的保留草稿（实现前原型）
选定图retained-draft-v1.png、提示词retained-draft-prompt.json。白底卡片、琥珀色已放弃说明、原编辑草稿只读Markdown/标签或任务日期状态；蓝色描边返回并保留，红色清除此草稿。只清除当前本机完整编辑草稿，不删除已保存资料、不触发SQL创建。清理前绑定当前cancelled ledger、规范scope、完整草稿摘要、origin已退休和fresh receipt仍缺失；草稿/ledger/receipt变化则保留并要求重新核对。读失败不能显示空草稿，不得自动清理。英文320dp/200%文字可滚动。


### 终态记录的明确移除（实现前交互补充）
沿用现有助手草稿卡，不新增页面。仅本地已创建/已放弃卡在Root提供安全回调时显示“移除此记录 / Remove this record”；pending、committing、unknown不提供清理捷径。确认框明确只移除列表中的这条记录，不删除已保存资料或保留草稿。未确认不调用清理；执行中禁止重复点击及继续发送，成功后重新读取当前会话/草稿列表，不凭乐观本地删除释放配额。安全回调需以元数据确认没有关联marker或编辑器vault、没有活动owner；不满足时保留记录，提示“仍有关联草稿，请先在本地备份的恢复管理中处理”。所有删除仅加密ledger记录，须durable写入和读回；未知存储不冒充成功。6条配额继续限制当前记录，明确移除安全终态后可继续提议，不自动prune任何历史状态。
