# 13 选中文字摘录与阅读位置（实施前补充）

原型13-excerpt.png：在原生Markdown文字选择菜单保留平台复制/全选，增加“摘录为笔记 / Save excerpt as note”。选择仅产生待编辑草稿，进入现有笔记编辑器确认后保存，不在选择或菜单弹出时自动创建资源。复用现有安全草稿、附件和NotesRepository；新草稿空间/成员隔离，与普通新建笔记共用明确的恢复机制，不静默覆盖已有未保存新笔记。

摘录保留选中的纯文本，转Markdown引用时转义语法字符，逐行添加>；附真实书籍、章节、文档标题与文档ID。服务器空间来源链接使用同服务器已存在的/ books/:identify/edit?doc=ID 路由（实际拼接去空格且按路径编码），本地仅显示名称和ID，不伪造可点击链接。用户想法在编辑器正常补充。选中内容为空或超限时不提交。

阅读位置记录是当前设备的近似滚动比例，不宣称逐字精确同步。按空间/成员/文档ID安全存储；比例0—1、文档修改标记；不同字体/屏幕或文档更新时仍由用户明确点击“继续上次阅读 / Resume reading”后恢复。无位置不显示提示，不造百分比。位置读写失败说明原因且正文仍可阅读；切换文档前保存当前文档的位置，旧响应不能写入新ID。暂停/后台时保存；存储队列维持顺序，离开时处理写入失败，不记录未布局的空滚动位置。未来跨设备同步单独按真实后端能力实现。

实现共用BookstarkMarkdown平台原生文本工具栏，不自行拼接假选区；测试真实选择传入的文本和来源。浏览器截图不代替Android选择手柄与长按真机验收。

验证：摘录菜单不写库、确认只创建一次、放弃不创建、已有新笔记草稿不被覆盖、转义多行/emoji/链接字符、来源编码/域名前缀、错误及长度限制；位置命名空间隔离、损坏记录、字体变化/内容更新、快速文档切换、保存失败和真实原生选区。
