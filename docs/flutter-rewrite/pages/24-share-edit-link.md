# 24 编辑链接验证入口：实现前原型

2026-11-05。24-share-edit-link.png先生成并发送。蓝色链条/钥匙图标，大标题“使用分享者提供的编辑链接”，普通链接只读说明；白色圆角表单完整链接输入、仅本次会话说明、验证并打开；底部同源核对信息卡和能力保管说明。布局16dp，最大600dp宽，可键盘滚动。手动粘贴，不自动读剪贴板或记录最近链接，不弹出系统分享带secret URL。

仅接受当前已连接服务器完整HTTP/HTTPS公开网页/shares/:identify?token=实际token，校验scheme/host/port/base path，无userinfo/fragment/重复token/额外参数/私有API/跨服务器。实际Go token为32随机字节的64位hex，不能把账号token或负share_id当编辑能力。identify按真实Unicode/字面百分号编码一次；受限请求由模型构造固定API路径，不把任意输入URL带认证发出。错误不带原输入或URI，输入关闭键盘个性化学习、建议和自动填充，不落盘。

用户验证通过再进入共享编辑；普通阅读页无token不启用owner编辑。可在分享阅读更多菜单提供此入口，用户需持有分享者给出的真正编辑链接。链接验证与目标打开间权限可能改变，编辑器仍每次读/保存校验；不把首次成功当永久权限。回归含跨源、前缀、重复/未知参数、无token、编码与恶意路径、失效能力、取消无写入、小屏与键盘。
