# 17 主题活动日历（实施前设计）

原型17-calendar.png：白色标题栏、共享月历卡片/前后月、周一首列42格、真实活动计数、选中日分类统计、明确筛选此日期。2026-11-01为周日，4为周三；示例7项活动=主题1+小结2+资料3+任务1，不是7个主题。

从TaskMonthGrid提取共用MonthActivityGrid，旧任务包装器保留原键/事件/修改任务文案；主题传入日期→活动总量及独立无障碍文案，不能拿TaskDailyCount当成主题数据。数据来自TopicsRepository.dailyCounts，1970—9999年，保留服务日历日期不转换UTC。只选日期不写资源；点击筛选返回YYYY-MM-DD给真实主题查询。切月份generation隔离，失败明确计数不可用，不显示全0冒充成功；旧月数据不能带入新月份。

日期格受7列窄屏宽度约束，保持至少48dp行高与完整日期/活动数语义；大字体调圈大小和格高，其他操作≥48dp；整体滚动、数字>99显示99+而分类卡片和语义保留真实总数。计数加载中与失败分别说明，重试实际重新请求。月份首尾禁用越界，选中日期与显示月份一致。日历count聚合多类最新活动，不代表历史事件日志。

复用后回归旧任务日历：键task-day:YYYY-MM-DD、选中/前后月、任务修改日语义、counts unavailable、不造截止日期计数、320dp英文200%字体。主题增加真实Go/本地calendar分类合计、首尾月份、UTC跨日、加载失败/旧响应、显式筛选、原型截图与真机。当前先设计，再实现共用网格和主题页面。
