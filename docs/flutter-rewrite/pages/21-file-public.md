# 21 文件公开设置：实施前契约

原型21-file-public.png在UI前生成：文件身份卡、公开无需登录/缓存可能保留警示、独立公开路径输入、不影响网盘位置说明、保存后服务器返回真实地址说明、确认公开/取消、后续内容更新影响公开地址说明。初次进入只读，无自动公开/复制假地址。当前已公开时显示真实已保存路径、确认过的canonical URL与复制/取消公开；用户编辑路径但未保存时不把草稿地址当有效URL复制。

只为服务端文件提供公开操作；本地空间不造公开服务。输入路径遵循Go NormalizeDAVPublicPath的真实约束（实现前继续读取对应函数），不把文件相对路径与公开路径混为同一命名空间。POST成功必须验证真实asset、node_id、公有路径与url；回读节点状态确认。请求失败/403/大小超限/冲突显示真实错误，响应未知先回读is_public/public_path而非盲目重POST。取消公开再次明确确认后DELETE并回读，不宣称缓存全清。文件被另端更换ID、移动或删除时停止操作，提示刷新原文件。打开链接或分享链接仅用户明确点击才触发，不附登录Cookie给外站；保留修改原文件会更新公开内容的提示。

测试实际Go公开前不可访问、公开后匿名读、内容覆盖ETag变化、公开路径冲突、取消后新请求不可用与已有缓存限制、未知响应回读、退出不写、字体/键盘/原型对照。设计中，未实现。
