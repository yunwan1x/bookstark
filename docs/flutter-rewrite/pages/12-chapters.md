# 12 章节目录与文档管理（实施前设计）

原型：12-chapters.png。顶部真实书名、返回、设置；本书文档搜索；章节树卡片、展开箭头、文档菜单；右下新建。树节点本身也是文档，不把父章节误当文件夹而丢失其正文。示例共7篇：两个父文档、四个子文档和附录；实际数字从完整接口树计算。

复用应用 Slate 主题、18sp 标题、14sp 列表标题、48dp 触控目标。树深度较大时限制视觉缩进并显示层级路径，保留全部层级。搜索按本书标题匹配并保留祖先路径；无匹配显示空状态。中英文和320dp两倍字体可滚动，底部留出 FAB 空间。

实际 API：GET /api/books/:id/docs/tree；GET /api/docs/:id；POST /api/books/:id/docs {document_name,parent_id,doc_type}；PUT /api/docs/:id；DELETE /api/docs/:id；PATCH /api/docs/:id/reorder {direction:up/down/indent/outdent}；PATCH /api/docs/:id/move {parent_id,order_sort}。移动前阻止自身/后代/跨书籍作为父节点；服务端成功后重读真实树。删除明确整棵子树，失败不从界面移除。新增父节点必须来自同一本书；失败后保留名称与父节点。

文档名称上限200 UTF-8字节；Markdown正文500000字节。注意旧 UpdateDocument 同时提交非空名称和空 markdown 会忽略正文清空，因此正文保存必须单独 PUT {markdown:...}，名称另行更新并保留部分成功状态，重读验证。非Markdown文档保留类型，进入后续对应原生编辑器，不误解码或覆盖原格式。

目录菜单：打开、重命名、新建子文档、上移/下移、缩进/提升、选择父章节、删除。无关分享/高级编辑器/朗读分别在后续页面设计，仍计入总目标。阅读和编辑独立先出原型后实现；不要用占位阅读页宣布完成。

本地存储须在事务中维护文档计数、父子关系、同书约束、循环检测、排序和完整书籍/子树回收站快照；新版本升级必须保留已有笔记、文章、待办、书籍ID。实际旧安卓迁移仍是44项，不能用新建本地库代替。

真实 Go 回归补充：Book.Insert 会自动创建一篇同名 Markdown 文档，列表计数初始为1，本地保持一致。DELETE /api/docs/:id 明确拒绝带子文档的节点；目录删除交互据此改为：父节点提示先移动或删除子文档，叶节点确认后删除。不会由客户端循环删除模拟原子子树操作。上文子树删除设计以此实测修订为准；整本书删除仍需完整文档快照。

验证：空树/多层树/搜索祖先路径/异常重复ID与循环、父节点校验、正文清空、重命名部分失败、创建重试真实ID、排序/移动/叶节点删除及父节点拒绝、全书完整快照与升级、真实隔离 Go 接口、浏览器截图、真机回归。没有真机时不标记完成。
