# 23 分享设置：实现前原型与协议

2026-11-05。先生成并发送 `23-share-settings.png`，然后实现。浅蓝底、白色卡片；顶部资源名称与当前状态，阅读链接卡、编辑权限卡、内容保护卡与底部停止分享。支持窄屏、大字体与键盘滚动。原型展示显式发布成功后的状态，初始未知状态不假造地址。

旧 Android SharesPage 实际跳公开广场，不存在可信的“我的分享列表”API。本页管理明确的当前资源：blog、book、document。GET /api/shares/status?type=&ids= 返回布尔映射，无链接、令牌或分享详情。只读加载状态；用户明确确认公开后才 POST /api/shares，不能为了获取链接自动发布。blog 发布会改变 visibility=1。真实回执含 share_identify 与可选 edit_token，只有收到有效回执后显示可复制地址。阅读地址不含编辑令牌。

PATCH /api/shares/:type/:id/edit-token action=enable/reset/disable；令牌重置非幂等，断线后不自动重试，旧令牌立即失效。未知写入结果保持本会话状态，先读取布尔发布状态；仅凭布尔不能判定令牌结果，不声称已恢复。用户若要重新获取当前链接，需要显式重新发布并说明公开副作用。book 不提供编辑链接。POST publish 的 enable_edit 会拒绝 protected blog；PATCH edit-token 本身不检查保护状态/类型，因此客户端不能声称服务端在所有端点均禁止。原生整书不提供不可用的编辑链接；受保护笔记的编辑仍要求独立密码验证。已有令牌后设置密码的情况按真实服务处理。

DELETE /api/shares/:type/:id 撤回，按真实服务 owner/admin 权限。停止前确认阅读和编辑链接失效；不自动重发非幂等写入。加载失败与未发布区分。密码管理复用 owner 笔记接口与原生独立密码流程；document/book 没有该密码入口，不把共享解锁接口误用为设密。现有 NotesPage 尚无更改密码 UI，原型按钮接入前须另补密码管理原型与文档。

令牌只在内存，复制编辑链接是用户明确动作，不加入阅读链接、日志、草稿、导出、错误文本或持久存储。隐藏/离开后清理。客户端分享管理不改生产 Go 协议。需验证实际发布回执、状态布尔、重置/禁用/撤回、权限失败与未知结果、受保护笔记限制、可访问对话框和真实 Android。当前为设计，尚未实现。
