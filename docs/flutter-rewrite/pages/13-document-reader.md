# 13 文档阅读与摘录（实施前设计）

参考13-document-reader.png：原生标题栏、真实书籍/章节路径和更新时间、共享Markdown阅读卡片；底部上一篇、编辑、下一篇，窄屏/大字体允许换行。内容可选择；图片用现有附件组件鉴权和缩放，不用WebView。上一/下一来自实际接口，首尾禁用并保留语义，切换后滚动复位；不跨书籍读取错误导航ID。

加载失败保留重试；快速连续导航用generation隔离旧结果。编辑完成重读当前文档；返回目录显示真实变更。非Markdown类型进入后续对应原生编辑器，不以空Markdown覆盖原始内容。

菜单支持刷新和明确的全文复制；摘录/关联笔记后续须独立补齐设计和实现，仍属13未完成项。朗读、流式EdgeTTS/后台控制在14，不能把简单阅读等同完整阅读功能。原型当前只表达基础阅读状态。
