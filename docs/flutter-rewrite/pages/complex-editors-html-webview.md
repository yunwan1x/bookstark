## 编辑与持久化边界

surface seed 仅在首次打开/显式采用新版本/重载时替换，不将每次 controller 通知重设为新文档。Web 引擎 dirty 通知用于安排检查点；保存、模式切换、离开不能依赖其及时到达，须锁输入并抓取当前 generation 的真实分块快照。标题与标签和该快照组成一个冻结的 HtmlNoteEdit。保留现有 HtmlEditorController、仓库、创建幂等键、专用 HTML 恢复 preferences 和 commit 屏障。

普通快照、恢复写入、保存和主动模式交接串行；保存同步建立屏障并等待旧草稿作业，pending 落盘后才调用 SQL/HTTP。pending/未知结果期间禁止普通草稿覆盖日志，禁止自动重放保存。所有 await 后检查页面是否存活及 surface 身份，旧 generation 不得改新页面。

新增 result-bearing saveWithOutcome，保留现有 save() 兼容接口。仅对实际仓库返回、allReceiptsKnown 为真且标题/原文/标签与冻结输入完整一致的结果确认 Web 快照。只读核对得到 observed 不伪造回执，不确认 host dirty。已知保存成功而恢复清理失败，仍保留真实回执，后续只重试恢复清理；不得重复 SQL/HTTP。

正常切换源码/预览及返回须先完成持久化屏障；失败则停留并显示可重试状态。安全或系统强制退休仍须关闭原点/租约，不能为保留编辑而把旧 Cookie 权限交给新页面；失败时不得冒称草稿已落盘，保留已捕获的内存草稿并呈现错误。此强制关闭策略与主动导航的可阻止策略须区分，不直接让 beforeRetire 异常吞掉用户主动离开失败。

## SQLite 入口

LocalHtmlNotesRepository._read 先在同一 transaction 读取 metadata，不选择正文；检查 id、collection、editor_type、删除状态和现有字节上限，再用固定 notes.content BLOB 分块读取，严格 UTF-8 并保留 BOM。保存基线检查和 transaction 内保存前/后读回也必须使用该读取逻辑，不能只修首次打开而在保存时重新整行读取。标题、正文、标签、创建回执、资源授权和原14表/2文档/5附件保持原业务语义。

保留既有 HTML 页面、controller、恢复、创建、保护、Cookie/资源/外链/后台回归。新增真实回执返回、未知不确认、快照晚于保存/旧代失效、草稿失败阻止主动切换、保存与退休竞态、待核对不覆盖日志、mode 互斥和加载前保存禁用。无需删掉 vendored re_editor 的历史生命周期测试或许可；此阶段不再把它作为 HTML 正文编辑界面。

## v10 页面接入前细化（2026-11-07）

源码协调器由页面默认持有，生产入口统一使用既有 CodeMirror WebView；测试可注入 sourceSurfaceBuilder，但不得以平台不可用为由改用旧原生正文后声称迁移完成。保存按钮须等待经过验证的 load generation，不能等待首次 dirty 事件才认定初次就绪。onReady 绑定传输身份及 transport.generation；旧实例、错误代次和晚到回调均拒绝。

源码切换至预览在持久化成功后还须等待共享租约实际关闭，再替换视图；快速切回源码也必须等前一退休完成。已知保存回执只更新 controller baseline，当前挂载的 seed 保持不变。标题、标签更新与抓取/保存共用串行队列；保存同步建立屏障后，晚到的 metadata 修改须有可见拒绝状态，不得改变正在提交的冻结值。

已有 pending/未知保存结果的离开检查只刷新原日志，不再捕获正文或创建新保存；核对是 observed 时仍不是回执。校验或提交前存储失败且无 pending 时允许解除输入锁后修正，未知、冲突或部分结果保持锁并提供明确核对/重载路径。页面先移除监听，再等待协调器队列结束后释放 controller，避免关闭过程中写入已销毁对象。

HTML 换行约定：未修改时始终返回原始完整字节；发生编辑后，对于原先统一采用 CRLF 或 CR 的文档，快照按该既有换行风格输出，避免修改一个字符导致整篇换行变化。混合换行文档发生编辑后沿用既有 CodeMirror 的编辑语义，不承诺逐行恢复混合分隔符；BOM 与 Unicode 由原格式保留。不得把混合格式的已编辑正文声称为逐字节未变。


## v13 只读源码接入前约定（2026-11-07）

沿用既有版本/恢复核对原型的标题、只读标识、标签、预览/源码切换和固定高度源码面板，不改变布局。HTML新建页暂不混入这一只读显示迁移。已有只读HTML的readOnly模式会渲染网页，不能拿它显示源码；增加仅HTML可用的sourceReadOnly模式，仍由既有CodeMirror WebView呈现，源码中的脚本不得执行。

此模式从加载开始锁定修改，使用CodeMirror公开只读/不可编辑facet并保持可聚焦、选中、滚动、复制；不使用inert阻断全部交互。拒绝输入、剪切、粘贴、拖放、撤销修改和保存快捷键，也拒绝解除锁。传输须校验对应generation、sourceReadOnly及输入锁回执。其他五种引擎及原来的readOnly/default路径保持兼容。

核对页只有不可变版本正文，不持有仓储或保存回调；恢复/创建控制器继续负责显式核对与fresh-read/adopt，绝不以显示正文代替保存回执。共享WebView租约仍负责生命周期和关闭。离开/重载/模式切换不得复用旧代次回调。

先做真实浏览器焦点、选中复制、输入拒绝、精确BOM/换行和退役检查，再冻结ARM64候选并在NAS redroid验证；fake platform/widget仅验证页面接线。v12单BOM检查点之外的连续BOM字节保真修复须覆盖空输入、BOM-only和非法UTF8，避免额外的大正文拷贝。全部45组目标不变。

## v13 新建文章源码接入前约定（2026-11-07）

沿用既有HTML新建v4原型的标题、标签、源码/轻量预览、保存及离开核对布局，用真实CodeMirror WebView替换原生源码正文；本地与服务器新建分别保留原有创建控制器和独立草稿命名空间。此步骤独立于上面的只读显示迁移，允许在同一候选中验证，不能共用已有笔记ID保存流程。

每次挂载只持有不可变源快照与稳定的mount key。正文快照、标题、标签在提交屏障内一起冻结；先可靠记录草稿，再由创建控制器可靠记录pending，之后才允许INSERT/POST。未知结果不自动重放，核对后fresh-read/adopt语义保持。成功关闭只退役一次，不因失效计数改变key而重新创建编辑器。错误回到可编辑状态时必须恢复输入；未知提交仍锁定。离开核对期间冻结元数据和操作，取消后恢复；草稿持久化失败留在页面并允许明确重试。

共享租约在切换、离开、后台时关闭；普通关闭须完成可靠快照，强制生命周期退役做有界的最佳努力捕获且不能否决关闭。晚到旧代次事件不能修改新页面，队列与快照句柄必须清理。成功真实回执不被视图关闭异常覆盖，也不伪造已有ID的确认。

验证包括双BOM/CRLF精确捕获、本地/远端页面真实控制器接线、未知结果和恢复不重放、失败解锁与离开冻结、立即输入后关闭，以及NAS redroid真实新建和独立SQL回读。fake transport只能证明协调与接线，不能代替真实WebView和Android驱动验证。
