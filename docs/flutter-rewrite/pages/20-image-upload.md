# 20 图片上传队列：实施前设计

先生成20-image-upload.png，再写UI。公开范围蓝卡、本次分类、真实多文件选择、待处理文件卡（原名/源文件大小/移除）、转换与复用说明、显式开始按钮。选择/移除/改分类不写远端。每个队列对象独立ID，重名文件不能互相覆盖；开始后冻结其实际分类，成功/复用/失败/结果未知分开呈现。处理完成以真实回复为准，不以流读取完成或100%字节发送冒充上传成功。

串行处理，停止可中止当前请求并停止后续，取消后仍需核对已发请求是否落盘。先准备有界不可变字节快照并计算原文件SHA256；GET哈希命中就复用，不发第二POST，未命中再上传。失败/中断未知先查哈希明确结果，禁止盲目再上传。已确认项保留真实ID；回复没有category/mime/time就不伪造，返回图库真实刷新。已有同hash可能处于不同分类且不授予删除权限。原始字节和服务器转换后大小分别标识，不将原始2.4MB当作存储占用。

真实FileSelector与系统取消/错误、HTTP发送字节计数、部分成功和恢复、停止/返回确认、加文件/去重/同名、客户端读上限与服务端动态限制、中英320dp200%回归。公开与本地空间提示不同；本地不会自动上传服务器。协议详见20-images.md。当前只出图/文档，尚未实现队列。
