# 07 知识库 / 笔记

原型 `07-notes.png`。24dp左右边距，原生标题/搜索/新建按钮，当前空间说明；笔记/文章/待办/书籍页签，搜索框与全部/最近/标签筛选；有标题、摘要、时间、标签和溢出操作的列表；底部导航与新建FAB。

数据：服务器 GET `/api/blogs?type=note&page=...&keyword=...&label=...&pinned=...` 的分页列表；本地SQLite相同Repository接口。标签、置顶、公开/加密标记来自实际记录。列表不下载全部正文；打开详情后才取内容。清空关键词恢复列表，分页不重复，刷新错误不冒充空列表。

交互：新建→08编辑；点击现有笔记按editor_type进入相应原生编辑器；受保护内容先解锁，不可把空的锁定内容保存回服务器。长按进入多选，菜单支持编辑、置顶、标签、可见性、移动到回收站等旧版操作；删除确认后更新列表，失败保留原条目。

首个实现批次先贯通本地/服务器Markdown笔记CRUD、搜索、分页和回收站动作；批量/标签/加密/其他内容类型仍是本页必须完成的验收项，不能以基础CRUD通过就标全页完成。文章、待办、书籍页签分别依赖09/10/11。

回归：离线创建并重启、服务器身份/CSRF、分页/搜索、重复点击与失败重试、错误保留、中文/英文、小屏/大字、返回列表后更新。当前：原型与文档完成，准备实现。
