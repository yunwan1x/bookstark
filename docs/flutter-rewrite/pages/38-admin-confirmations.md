# 38 草稿移除、整表保存与评论永久删除：实现前设计

2026-11-07。内置imagegen原型 38-admin-confirmations-v2.png 已先保存后实施。V1误生成技术性顶部标识和深色栏，不采用；V2修正为白色标题栏。三栏是独立流程状态，不能同时触发多个操作。

左栏是友情链接单条草稿移除确认，显示实际条目名称，明确只影响内存草稿；继续编辑零改动，移除只删列表草稿且没有HTTP写入。后续仍需保存全部链接才影响服务器。删除草稿不清除同组其它条目的描述、二维码或顺序。

中栏是友情链接整体保存确认，显示完整草稿条数和整体替换/并发覆盖警告。确认后发送一次完整 items 与 simple_mode，保留全部未编辑字段，1MiB与200项边界提前校验。空列表需同一明确流程并写出“将清空全部友情链接”；不能只显示0条而隐藏后果。返回核对不发送PUT。成功回执与GET核对分开，GET采用规范化后的语义字段，不按重新生成的ID假定同一资源。未知结果停止旧提交、先读取核对、不自动重放。

右栏是评论永久删除确认，绑定当前页实际选择ID和可见目标摘要；显示所选条数，明确删除主评论会连同关联回复，实际影响数可能更多，无法恢复。确认发一次 POST /api/admin/share-comments/delete，取消零请求。成功使用实际 data.deleted，包括真实0条；刷新后页码越界则明确转到有效页。没有审批、编辑、恢复接口，不能添加这些按钮。未知请求不自动重复，也不能从当前列表缺失证明上次操作成功。

共用尺寸390×844，16dp边距，12dp卡片，至少48dp点击，白/深蓝/蓝系统，永久删除使用红色和文字双重表达。320dp/200%字号时标题、警告和按钮完整换行，长内容滚动，操作不因键盘或缩放不可达。处理中锁定确认与其它写操作；会话、权限或页面所有权变化撤销确认并清理选择，迟到回执不修改其他会话。

后续测试包括取消零请求、选择ID/草稿版本绑定、主评论回复级联的真实删除数量、0结果、整表空数组与未编辑字段、规范化/ID重建、无隐式重放、401/403和取消。必须独立隔离Go SQL与NAS redroid ARM64验证；本原型不代表功能实现或验收。
