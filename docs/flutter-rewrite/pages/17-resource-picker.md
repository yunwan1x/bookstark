# 17 选择主题资料（实施前设计）

原型17-resource-picker.png。类型chips文档/笔记/文章/书签/任务、搜索、真实分页、选择既有条目、明确确认、真实已选数量。文档须先选真实书籍再读章节树，不能伪造全局doc索引。Notes/articles复用现有列表仓库和类型隔离，书签只取自己的完整记录，任务使用真实分页。选择或切换类型不会写资源；跨类型选择按type+target_id区分，重复引用标记实际已关联。

只有确认后调用对应topic资源POST；支持选定条目逐个添加，成功项保留实际关联ID并从待重试集合移除，失败项和输入留在页内。多请求不承诺原子操作；网络结果未知先回读topic已有引用核对，不盲重试。源资源不得被删除或修改，snapshot标题/描述用实际可访问元信息。受保护笔记显示保护状态，不解锁或自动读正文，不把密文片段当说明。最大选择数量可在界面明确限制，但不能冒充服务全选。

复用共享列表/表单/分页/标签与原生章节树样式；缺失源、无权访问、查询变化、空列表与网络失败区分。搜索generation、200%字体Wrap、48dp触控；实际源打开另由原生资源导航处理。当前原型和文档先行，UI尚未实现。
