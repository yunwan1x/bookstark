# 21 目录选择器独立原型

独立原型21-file-directory.png用于上传/移动/复制的目标目录选择。此前只有21上传原型中入口与功能草稿，本次补全独立视觉设计，再按图完善。状态实现中，不能把草稿写在独立图前称为已满足先设计要求。

白色AppBar返回+选择目录；浅Slate背景；16dp边距；面包屑蓝/灰圆角chips；只显示文件夹说明；当前目录卡（真实相对path）；返回上一级描边按钮；懒加载白色文件夹卡、黄色folder、实际名称/文件夹/chevron；底部安全区排除源目录说明与宽蓝色选择按钮。原型示例目录不写死在运行数据中。

仅GET list，不产生任何新建/覆盖写操作；实际目录读取失败不能选中或冒充空目录。切换目录代次隔离；移动/复制目录时禁止源目录及子目录，initial如果非法也应回到安全父目录；路径按DriveModels规范不重复URL解码。系统返回优先上一级，根才退出；列表按目录独立滚动位置。小屏200%说明与底部按钮保持可见可滚动。调用者收到完整实际相对路径，再执行仓库的目标冲突/基准检查，选择目录不代表写入成功。
