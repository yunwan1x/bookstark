# 08 附件链路实施设计（实现前）

视觉依据仍为 `pages/08-editor.png`：正文下真实附件行（图标/文件名/大小/移除引用），工具栏图片与附件动作，预览中的图片；继承编辑/保存/未保存返回、键盘和草稿状态设计，不引入新WebView页面。条目溢出可滚动，所有动作中文/英文且至少48dp。

本地：Android系统文件选择后以随机安全ID复制到应用持久目录，Markdown保存`bookstark-attachment:///ID/原名`引用；重新打开可读，不保存选择器临时路径。只接受持久目录已知ID，不可读取任意file://或路径穿越。失败保留正文；取消选择不改正文。移除引用不自动删除真实文件，避免破坏其他笔记/草稿；统一空间清理留到45。

服务器：非保护笔记的栅格图片沿用POST `/api/uploads`，其余文件和保护笔记图片走需登录的POST `/api/webdav/files/upload`。为避免覆盖用户同名文件，随机化存储名（保留扩展名），目标在用户根目录；服务端依既有文件配额返回错误，不伪装成功。保护笔记附件不调用公开图片上传入口，不持久缓存解锁内容。

协议集中在BookstarkClient，Multipart流式读取、Cookie/CSRF和错误解析共用。图片接口URL为/upload-files，下载不带凭据；私有WebDAV引用为/api/webdav/files/download?path=...，仅在当前服务器匹配的这两个文件路由上发送Cookie；外域图片一律无Cookie且不跟随重定向泄漏身份，非HTTP(S)和本地任意文件路径拒绝。反向代理路径前缀保留。

本轮图片预览设16MiB内存上限、分享读取设64MiB上限并显示超限；上传流不全量载入内存，大小提前检查并由服务端最终限制。使用Markdown AST收集真实图片/附件引用，重开编辑器仍显示条目；不以正则猜测复杂链接。插入链接转义方括号/换行并百分号编码URL；上传期间捕获并恢复插入光标，失败不插入虚假URL，保存/返回等待上传结束。

分享由用户点击调用Android系统分享面板，不自动发送给任何联系人。远程下载仅临时内存，插件分享文件可能落系统分享缓存；本地附件为应用持久数据。普通外链询问打开后交给系统浏览器，保护文件链接在应用内读取并分享，不将Cookie附到外域请求。

验收：Multipart实际字节/CSRF/非JSON错误/路径前缀；本地复制重开/原路径删除/路径穿越拒绝；受保护上传路由；有界下载和凭据隔离；Markdown链接转义/AST提取；真实选择取消、失败重试、附件行/删除引用、保存重开、图片显示/系统分享。平台插件动作保留设备测试门槛；fixture只能证明渲染和交互分支。
