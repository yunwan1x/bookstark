# 02 注册

原型 `02-register.png`，先设计后实现。24dp边距、标准返回栏、30dp标题、14dp说明、54dp外置标签输入框、52dp主按钮；允许键盘下滚动。

表单：服务器、账号、邮箱、密码、确认密码；邀请码默认折叠。提交前读取 `/api/register-config`；启用邀请码时展开并要求填写。POST `/api/register` 字段严格为 `account/email/password/confirm_password/invite_code`。前端验证邮箱、6字符最低密码和确认一致；服务端错误保留表单，提交中不可重复请求。成功后留在当前页显示服务端审批/注册结果，提供返回登录；不能误认为注册即已登录。密码不持久化。

加载/校验错误/网络错误/注册成功/待审批/中英与大字均需回归。原型中的“可选”在服务器启用邀请码时变为必填。当前：原型和文档已完成，未完成真机回归。
