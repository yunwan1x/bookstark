# 05 首页

原型 `05-home.png`。顶部品牌、语言和账号入口；空间选择条；欢迎标题与搜索；最近记录；两列三行快捷入口；AI入口；5项底部导航。

所有列表来自实际Repository，原型样例不得作为生产数据。服务器首页复用 GET `/api/home`，解析顶层 `recent/sections/layout`，加载、无记录、401和网络失败提供各自状态，刷新可重试。本地首页读取新客户端SQLite文件中的内容，不依赖手机内Go。最近记录路由只接受本应用已注册的内容类型，不直接把返回的任意URL加载为网页。

导航依赖：笔记、书籍、待办、书签、主题、文件、搜索、AI、个人资料、空间切换页全部接入后才算导航闭环完成；未实现的依赖不能用静态占位页冒充完成。首页布局编辑和最近清理按旧版能力另补交互原型，当前基础原型不代表旧版配置能力被删去。

验收：真实数据/空状态/加载失败/重新登录；五导航与6快捷入口、刷新与返回；中英和大字体；截图对比原型。当前：基础原型与文档已完成，待实现和依赖闭环。

### 窄屏与大字补充（实现前）

390dp正常字号维持原型双列快捷入口。按标签实际所需宽度分配列数：每格至少140dp乘文字缩放，最多两列，不靠固定2.4宽高比裁切英文。320dp或大字不足以容纳两格时单列，行高按文字缩放取4dp整数基线，至少56dp。整个首页可滚动，入口继续复用FilledButton.tonalIcon；新增文章/待办入口均须保持可触达。回归320×568、英文200%文字及残留键盘高度，确认可点击真实tasks路由。
