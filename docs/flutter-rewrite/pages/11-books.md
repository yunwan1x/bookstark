# 11 书籍列表、新建与设置（实现前设计）

书架原型 `11-books.png`，内置imagegen，原始提示词同名prompt.txt。白色56dp AppBar/返回/书籍，16dp边距、搜索书名或标签、书架标题与最近更新说明，白色8dp边框行卡：蓝色书籍图标、14sp/600名称、说明、实际标签文本/文档数/更新时间、更多菜单。蓝色圆形新建按钮。没有封面上传或阅读百分比：现有书籍接口没有这些字段。新建/设置另有补充原型和文档。

## 已核对的服务端契约

- GET `/api/books?page=N&keyword=...`：data数组（空可为null），total/page/page_size。按modify_time倒序，搜索书名或镜像label字段。列表book_id/book_name/identify/description/label/doc_count/create_time/modify_time；modify_time可为null。真实doc_count缺失时不编造0，不把它当阅读进度。
- GET `/api/books/:id`：data为完整Book，另有权威labels名称数组。保存设置必须先读取详情，不把列表label字符串猜成标签数组后写回。列表标签是CSV镜像，含分隔符的单个名称存在歧义；列表可原样展示标签文本。
- POST `/api/books`：book_name/description/labels字符串。书名不能为空，UTF-8上限200字节，说明2000字节（Go代码按len，而非字符数）。identify由服务端生成，原站设置也没有自定义标识输入。返回完整Book及book_id。
- PUT `/api/books/:id`：同三个可编辑字段；不发送或重置identify/item_id/order_index/doc_count/is_use_first_document。重名409需保留输入。创建/更新中的标签绑定错误有忽略分支，客户端须用专用PUT `/api/labels/resource/book/:id`并读取标签核对；元数据已保存而标签步骤失败时保留真实ID，重试PUT，不能再次POST造成副本。
- 资源标签接口仍是逗号/中文逗号分隔字符串，不支持引号转义。已有标签名应原样保留（包括空格），不能自动trim或拆开名称。无法无损编码的单个名称须在写请求前明确拒绝，保留当前内容；不静默改成多个标签。新输入的多个标签可按用户输入分隔符明确拆分。
- DELETE `/api/books/:id`：删除整本书及文档、相关分享；现有Go实现会尝试建立回收站快照，但快照失败仅记日志继续删除。确认文案应明确“删除书籍及全部文档/相关分享”，不向用户承诺一定可恢复；本地实现则在事务中写快照失败即不删除。

## 原生行为

- 本地/服务器空间共用BooksRepository；完整分页，搜索旧响应不能覆盖新查询，失败/空白/重试可见；操作后重新核对已加载页，避免偏移变动漏记录。卡片点击接12原生目录，设置/删除走独立菜单，不用网页包裹。
- 新建成功转入真实书籍目录；目录12未实施前11保持实现中，不能以占位页宣称闭环。书籍设置只改书名、说明、标签，保留正文和层级。
- 标签编辑用共享原生选择器：真实已有标签查询、添加/移除、取消无写请求，最终保存再提交。保留已加载名称原值，显示截断不能改变存储值。新建100字节限制与全局标签创建接口一致，已有名称不自动删改。
- 安全草稿按空间/账号/资源类型/书籍ID隔离；保存中输入不覆盖，部分创建有ID后不重复新建，失败保持输入。离开使用保存/保留草稿/放弃/取消；存储失败可重试，不能悄悄丢草稿。
- 本地SQLite新增独立books表，已有v1—v4笔记/文章/任务与ID保留；名称活动唯一、标签JSON原样保存。章节12加入后，文档计数与整本删除快照在同一事务维护。不动旧Android库；原始迁移44另行验收。
