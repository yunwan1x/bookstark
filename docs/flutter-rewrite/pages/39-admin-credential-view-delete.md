# 39 凭据明确查看和删除：实现前设计

2026-11-07，先核对controllers/assets.go、models/asset.go及static/js/assets.js，再内置imagegen生成/查看39-admin-credential-view-delete-v1.png，图片和完整提示词已保存。原Web编辑会预填已有秘密并可显示；Flutter用独立明确查看保留这一能力，编辑保持新秘密初始为空以避免无意回传旧值。全为虚构数据；尚未实施/验收。

白底/深蓝标题/浅蓝资料卡、16dp边距、至少48dp目标。查看页显示名称/用户名/认证方式，秘密区域默认闭眼图标与固定掩码，不以圆点数量泄露长度。点击“显示秘密”才开始新的同一owner/session/role0核验和只读请求；没有点击时不把列表中收到的秘密存进页面模型。实际无可用值则显示“服务器未提供可查看的秘密”，不能造一个空值或用掩码作为秘密。显示后按钮变为隐藏秘密；长私钥用受限可滚动只读文本，支持换行，不进入编辑缓冲。

没有GET单凭据接口，实际需GET /api/admin/assets/credentials全数组。网络层因此会暂时接收所有返回值；解析器只把明确目标ID的秘密交给短生命周期查看对象，其余立即丢弃引用，元数据DTO不持有raw map。不能声称服务端不返回秘密或Dart内存物理零化。显示前核对目标当前元数据，若已变化/删除先回到新资料核对，不自动显示后来同名凭据。请求关闭/失权/换空间/注销与后台取消；迟到结果不能重现。隐藏/后台/返回/打开别页清理秘密引用并重置掩码，再显示重新读取，不从本地恢复。禁止写入磁盘、普通草稿、日志、错误栈正文或截图。

Android查看路由应使用作用域内FLAG_SECURE租约，防系统截图/最近任务缩略图暴露；离开释放且不影响其他已有租约。Web只能按生命周期清除显示，不能承诺浏览器阻止系统截屏。设备证据只在隐藏状态截图；用自有fixture做行为验证，不导出秘密文本。没有加入原功能不存在的复制动作。

删除页独立红色确认：明确不可恢复；存在SSH/WebDAV引用时服务端会拒绝删除。只展示安全元数据，不带查看页的秘密。不存在全局使用数接口，不能显示假0或假“无人使用”；后端DELETE /credentials/:id的400绑定引用检查是最终依据，错误显示受控本地消息，不呈现原始服务端字符串。删除前fresh profile+完整列表核验ID/基线，取消不请求，单次提交，不自动重发。Go未返回affected rows，不能声称恰好删除一条或把code0等同存在性证明。已回执/回读失败只GET；提交后断线未知保持未知并要求明确只读核对，不凭缺失推断上次成功，也不补删其他同名ID。
