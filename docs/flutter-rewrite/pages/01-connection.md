# 01 连接与登录

设计先于实现。原型：`01-connection.png`。对应旧版 `/login` 与新客户端空间选择。

## 视觉规格

- 390×844dp 设计基准；横向内边距24，浅 Slate 背景，蓝色主操作，开放书本图标。
- 安全区域顶部右侧中文/EN；主标题30/700，说明14；空间分段控件；三个带外置标签的输入框（54dp）；主按钮52dp；底部离线说明。
- 服务器空间：地址、账号、密码、密码可见切换、忘记密码、注册入口。
- 本地空间：保留标题、分段控件和主要操作位置；隐藏服务器账号输入；明确离线本地内容边界。
- 窄屏和键盘展开时页面可滚动，文本放大不截断，不以固定屏幕高度压缩字段。

## 行为与接口

1. 校验服务器URL、账号、密码；禁止URL内嵌凭据/查询参数/fragment，仅HTTP/HTTPS。
2. POST `/api/login`；Cookie会话由统一客户端捕获；成功后进入首页。
3. 写请求先获取 `/api/csrf-token`，在相同域保存Cookie并发送 `X-CSRF-Token`。
4. 登录中禁用重复提交；错误留在当前页面、保留地址和账号，密码不写偏好存储。
5. 本地模式不发登录网络请求；注册/重置路由按各自页面的先设计后实现流程接入。
6. 中文/英文界面即时切换；视觉原型为中文态，英文需相同布局约束。
