# 36 系统提示词与编辑动作：实现前设计
2026-11-07。原型为示例，无真实AI请求；未实现。
系统提示词以Markdown/HTML/画板分别对应ai_system_prompt_md/html/drawing；编辑动作以选中文本/HTML/书籍/文章/笔记/待办/空场景对应ai_actions_selection/html/book/article/note/task/empty。读取整体settings后，仅显式修改且值实际变化的本页字段PUT，未知字段与AI计数不提交。场景切换保留独立内存草稿，不误把上一场景文本提交给新key；离开有改动须保存/放弃/继续。
提示词/动作是原始纯文本，不执行HTML或脚本、不调用模型。动作每行label | prompt，#开头注释；未改动文本精确保留注释、空行、占位符{subject}与未知格式，不通过结构化编辑无声丢弃内容。错误行需要明确提示，不能擅自清空整组。普通多行文本框，长文滚动、键盘与底部保存始终可达；320dp/200%文字时场景chips换行，确认框可滚动。
默认值以服务端models.AIDefaults为准，不在客户端硬编码一份伪装当前服务默认。POST /api/admin/settings/ai/reset，body仅{key}，服务器白名单只接受上述10项，成功返回data.key/value。这个API立即写库，故恢复默认先弹确认：将覆盖这项服务器保存值及当前这项草稿，其他场景草稿不变。取消无请求。发送期间冻结场景与输入；只有实际成功并返回匹配key和string value才采用，未知结果不自动重放，重新GET核对。不能把该按钮当草稿重置直到保存才生效。
Go启动会回填当前为空的AI默认项，因此保存空字符串后重启可能恢复默认，UI应说明而不保证永远清空。保存/恢复均fresh管理员检查、请求会话ticket、取消与旧generation拒绝，401/403清理资料及表单，无配置持久化/日志。
测试覆盖精确10key、默认恢复实际SQL及仅单key变化、取消无POST、结果未知不重放、迟到场景响应不覆盖别的草稿、注释/空行/分隔符及占位符精确保留、长文本/窄屏大字体；隔离Go与假模型，NAS redroid真实输入/保存/恢复独立核对。不完成其他36子页或全部45组。
