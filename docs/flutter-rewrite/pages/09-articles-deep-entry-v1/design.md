Scope: authenticated remote search/topic/label/recent article results open the existing Go article WebView. Ordinary note Markdown remains native; local and anonymous flows retain separate storage/security and remain subsequent work.
UI: a Flutter return-to-source header and Article title stay visible during identity resolution, WebView loading, editing and retryable failure. Source-specific return label may be generic Return when launched outside search. Source results are not redesigned in this increment. Web editor chrome, source controls and body come from Go and are not recreated from illustrative mockup.
Resolve numeric blog ID through authenticated same-server GET /api/blogs/:id, validate returned ID/member/type/identify before constructing an encoded editor route. Never accept open_url, numeric-ID-as-identify fallback or body/password supplied by native code. Validate again after awaited work/current account generation; no unlock dialogs before Go.
Metadata extraction must stream and discard blog_content/blog_desc without allocating whole body. Strict UTF8/JSON, byte/depth/token/retained-metadata limits, duplicates rejected, cancellation/deadline and redirects fenced. Large legitimate Go source must not hit 128KiB settings receipt cap.
Reuse ArticleWebSession profile, cookies, secure-window and retirement queue; initial entry is a typed validated editor URI within the configured prefix, checked by Dart AND Kotlin. Back first respects Go history/unsaved confirmation, then closes runtime before returning to source. Account expiry closes before connection handoff. Native module links must retire/pop source route via a deferred root handoff, not get swallowed by _openingFeature.
Tests: large/chunked/escaped/malformed metadata; identity/member/type mismatch; cancellation; prefix Unicode encoded identify; invalid traversal/entry rejection; native opener bypasses Markdown repository; load/error/retry/back and close-before-navigation widget tests; full analysis/tests ARM64 build then new isolated redroid cases with actual Go save/protection/return, original43 restored.
