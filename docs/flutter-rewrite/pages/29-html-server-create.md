沿用已先生成/保存/发送的29-html-v4-local-create.png第3屏（普通未知新建）及29-html-v3-recovery.png保护只读核对。普通编辑表单延续本地新建布局，身份显示服务器空间与实际目的服务器；未保存/未知阶段采用不运行脚本的轻量预览，保存或明确采用后进入已有完整认证HTML页。不能在预览中提前执行资源修改脚本。

## 已检查的真实协议

当前Go POST /api/blogs需要blog_title/blog_content/blog_type/editor_type=html/labels字符串CSV/visibility=0。正常返回完整Blog对象，包含压缩编码后的blog_content，不是仅返回ID，因此不能套128KiB设置回执上限；按5MiB源文上限计算，创建回执最多读取8MiB，严格UTF8/JSON及成功码/正ID/身份/类型。JSON请求最多32MiB，HTML最多5MiB，标题最多200UTF8字节。所有请求同源、固定API、Cookie/CSRF、禁止重定向、有取消和截止时间。

创建与绑定标签不在同一事务，标签绑定错误未返回给客户端。必须读原始HTML/元数据/标签再确认。笔记允许重复标题，不能凭标题认定是这次创建；文章有重名限制。客户端的随机创建键不会发给旧接口充当虚假幂等支持。

另外，响应读取超出客户端上限必须归为未知结果，不能把本机读取上限产生的413误当服务器拒绝写入。

## 状态与持久化

先校验输入，再持久化pending意图并等待原生存储确认，才允许发起唯一POST。收到真实正ID后，先持久化created_id再作后续读取或标签写入。记录写入失败只重试记录，不能重POST。已知完成而清理失败只重试本机清理。重启后的读取结果是观察，不伪造旧回执。

未知且无ID时仅提供只读候选查找。先列同账号/同collection/HTML候选，再按用户选择读完整源码和标签；内容一致标记必须基于实际回读，标题一致不等于本次创建。多个同名结果显示真实ID与版本供选择；完整只读查看、明确采用、再次读取未变后才结束旧意图并打开该ID。采用候选不修改它的正文或标签。查找有分页、上限和网络错误状态，无结果不能自动判失败或重发POST。

已知ID但标签不一致，可在真实正文回读一致后明确继续保存标签，保存前再核对完整基线及标签；不得重发正文。未知ID的候选不能在用户采用之前自动补写标签。

## 保护与作用域

scope隔离服务器含路径/成员/note或article/html/new；本地与服务器使用不同业务前缀，远程旧恢复记录不改名。普通新建保留完整输入。若观察到服务器版本已受保护，先转换为只有身份、创建键、已知ID/候选提示及SHA256摘要的保护记录并等待存储，再请求解锁或展示保护源码。保护记录不存标题/正文/标签/密码。候选提示ID必须与POST回执ID区分，不能把猜测存成创建成功ID。

解锁密码只在当前阅读/编辑内存中使用，空格不能被trim。保护未知恢复沿用专用只读核对页；明确采用前重新读取，之后进入正常保护编辑。没有保存的标签明文时不自动补写，只能采用当前版本后开始新的明确编辑。
