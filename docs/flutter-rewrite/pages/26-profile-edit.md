# 26 编辑个人资料：实现前原型与协议

2026-11-05。26-profile-edit.png先生成并发送，再实现。顶部返回/编辑资料/保存，账号只读卡、联系邮箱白卡、默认打开模块白卡（八个真实模块单选）、蓝色回读提示及底部保存资料。所有内容可滚动，320dp和200%文字下模块卡换行，键盘不挡操作。没有服务端不保存的简介、昵称、头像上传或手机号。

读取GET /api/profile，核对实际member_id/account/email/role/default_home，与当前服务器/成员绑定。实际默认模块枚举home/notes/tasks/articles/books/bookmarks/nav/search；不因为未知值自动选notes并覆盖。PUT同路径只提交email和default_home；email经明确表单去除首尾空格后按服务验证，UTF8字节≤200，后续回读以实际存储值核对。资料不写临时磁盘草稿，不记录邮箱/认证Cookie/原始错误消息。

保存前重读，若服务器邮箱或默认模块与编辑基线不同，显示本次与服务器字段的冲突卡，先选择保留本次/采用服务器，再明确提交；记录原服务没有原子CAS，预读后到PUT仍有竞争窗口，不声称完全并发安全。保存期间保留后来输入，不把旧回执覆盖新编辑。成功回执与回读确认分开，未知结果先GET核对，匹配期望才确认；不匹配保留本次输入，不能自动再次PUT。明确重试必须再次核对当前基线。返回未保存/未确认时明确确认，不使用浏览器confirm。

默认模块更改仅影响后续进入服务器的入口，不在保存表单时突然跳页。应用语言另走原生偏好和根导航更新，不通过不存在的profile字段伪保存。子页完成后接我的页，未实现入口不放空回调。当前原型/协议，尚无本页实现。
