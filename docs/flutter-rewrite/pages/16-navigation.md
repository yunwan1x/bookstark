# 16 导航与快捷收藏（实施前设计）

原型16-navigation.png：原生白色标题栏“导航”、返回、管理书签；搜索快捷收藏；全部/实际分组chips、视图切换；置顶、按层级标签归组、未分组的真实收藏。列表卡片复用Slate主题、14/600标题、域名、说明、蓝色图标和有权限才出现的菜单。管理进入已实现15；编辑复用15编辑器/草稿和真实权限。中英、320dp及200%字体全部可滚动，模式按字号自动减少网格列数，不压缩触控区域。

API GET /api/bookmarks-grouped?scope=mine/public&keyword=&group=&labels= 返回顶层groups:[{name,bookmarks}],ungrouped,pinned,all_labels,total。原生保持服务器真实分组，不从CSV label猜标签；pinned不再重复加入groups。服务只取nav_visible=1，并受GetNavMaxItems限制；total是截断后、group筛选前行数，不能冒充所有库记录。分组由第一个含/且前缀非空的标签决定，分组按数量降序；服务端返回标签顺序可能影响归组。group筛选不剔除置顶，UI应尊重此行为。原界面也在已加载数据集上过滤分组，不能宣称筛选覆盖未返回的数据。

客户端搜索使用keyword查询（title/url/description），generation阻止旧响应覆盖。分组chips筛选当前返回分组，置顶始终保留；显示真实“当前显示N / 已加载M”，不能修改服务total掩盖差异。标签筛选若用服务labels CSV必须使用现有无损限制保护含逗号/首尾空白的旧名称；若在当前已加载集合筛选则明确范围。没有导航条目是空状态，可管理书签打开“显示到导航”。网络错误与空状态分开。

视图支持默认卡片、列表、紧凑，按账号/服务空间独立持久化视图和所选分组（安全记录存储，不混用原Web localStorage）；过期分组不阻塞数据加载。最多两列、按可用宽度和字体缩放决定；紧凑模式保留完整标题或可展开、域名和48dp操作入口。禁止固定高度裁掉大字体内容。外部链接沿用现有确认与系统浏览器流程，不附加登录Cookie。图标加载要复用现有无凭据读取/图像能力并有明确fallback，不能令图标失败阻塞卡片。用户信息网址的旧兼容性仍需覆盖，不能静默清洗既有URL。

编辑/隐藏导航/删除等按item.member_id和profile.role=0校验；公开他人条目只读，不能因已登录就允许写入。隐藏导航使用幂等PATCH nav-visible:false；单条置顶仅admin，继续由已有15仓库与真实权限处理，不调用管理员toggle盲重试。返回15后刷新，编辑仍保存完整旧标签；操作网络失败须刷新核对后再写。当前Web无有效order_sort拖拽呈现，模型导航查询也忽略order_sort：不能做会保存却看不到结果的虚假排序控件；15排序协议已接，可用于后续真正支持该排序的场景。

本地导航从SQLite7真实书签nav_visible筛选；同样排除软删除、分离置顶/分组/未分组、JSON标签完整保留、视图按本地namespace持久化。本地无公开网络列表，不能拿本地public标志冒充联网。此版本新库升级不等于44项旧Android Go数据库导入。
