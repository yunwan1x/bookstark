# 19 全局搜索：实施前设计

先生成19-search.png再写UI。单页包含未搜索、输入、加载、结果、空白、错误及保留旧结果的状态，不引入WebView。Slate背景、白色8dp结果卡、蓝色分类Chip和关键词标记；原生搜索框可清空，点击搜索或键盘提交，不在每次输入时隐式发送。按类型切换只过滤本次响应。中英、320dp/200%、键盘/滚动与读屏覆盖。

真实入口GET /api/search?q=，所有类型一次返回：documents,blogs,books,bookmarks,labels,tasks,topics，加counts。counts是本次数组长度，每类SQL最多20条，无page/下一页接口；ASCII词匹配又发生在SQL LIMIT之后，所以即使返回少于20也不能证明已列尽。页面只写“已加载N条”和“每类最多返回20条，数量代表本次返回结果”，不写全库总数、不用虚构加载更多。需要看更多时回到对应原生列表，不能用另一个模糊查询伪造同一结果的分页。

Go先trim查询，空值400；超过100 UTF8字节时直接q[:100]，可能截断中文编码。原生在请求前检查trim后1—100字节，不静默截词。服务端LIKE转义%、_、反斜线，ASCII纯字母数字连字符下划线使用整词边界匹配（word char为ASCII字母数字下划线）；中文等按子串。上层不要声称纯全文引擎、模糊联想或任意子词匹配。查询世代隔离，旧请求不能覆盖新结果；错误保留输入并标记旧结果对应的查询，不能把旧数组当新查询成功。

范围：资料按memberID，只查当前用户；标签全服务器共享，不用“全部是我的资料”。搜索受保护笔记时不匹配ENC:v1:密文正文，摘要优先公开描述、否则未加密非HTML正文；不生成或显示密文片段。HTML内容不匹配正文，标题/说明仍可搜。文档属于当前用户并连接书籍元数据。原生摘要按纯文本显示，不把返回文本当HTML执行；不加载任意外部图片、链接或脚本。关键词高亮只改变字形，不改变内容ID或安全边界。

模型：文档id/name/identify/book_name/book_identify/snippet；博客id/title/identify/snippet/blog_type，type真实note/article；书籍id/name/identify/description/doc_count；书签id/title/url/description；标签id/name；任务id/content/due_date/done/parent_id/snippet；主题id/title/question/snippet/item_count(资源关联数)。同数字ID可跨类型，使用(type,id)唯一键，不互相去重；每组重复ID或counts与实际长度不一致时拒绝响应而非制造统计。未知类型不自动当笔记。没有时间字段的卡片不加虚构日期。

打开结果：复用已实现原生文档阅读、笔记/文章解锁与编辑、书籍章节、书签、任务、标签详情、主题详情。点击分类/展示摘要/清空/搜索不执行资源写入。任务卡的勾选外观仅表示状态，不在搜索页自动完成；点击进入真实任务编辑。标签链接保持当前账号权限。受保护/删除/权限失败保留搜索页与查询并明确错误。返回后重新搜索原查询，确认列表真实状态。

本地空间使用真实SQLite各表与软删除条件，先同步持久标签登记，归档数据不参搜；文档book_id需有效。维持同样类型限制、长度、literal LIKE、ASCII边界、每类20候选后边界过滤的行为。包含主题问题/小结/资源快照/主题任务搜索，不能仅搜主题标题。图片管理等不在此旧API范围，不虚构为可搜索类别。新SQLite与44导入分别验收。

测试：DTO空数组/null、7分类、同ID跨类型、计数/去重、UTF8与emoji、%_\\字面搜索、ASCII边界和20条截断、保护笔记不泄漏、成员隔离、主题子资源命中、旧查询世代、纯文本高亮、取消/错误、真实源跳转、中英小屏截图与Go契约。当前19设计中，尚未实现，未标完成。
