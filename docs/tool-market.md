# 工具市场

开发者从 [插件开发指南](plugin-development.md) 开始，完整接口见 [工具权限与桥接 API](tool-permissions.md)，多文件应用的分发格式见 [工具包格式](tool-package-format.md)。

## 服务器公开市场

管理员在「系统管理 → 工具市场」配置启用状态、名称及对外访问根地址，保存后复制生成的 `https://服务器/market` 地址给客户端。`GET /market/index.json` 提供协议发现；`GET /api/tool-market` 提供目录。关闭市场后停止新的浏览和下载，已经安装的工具仍然可用。

目录默认允许公开浏览，安装默认要求登录发布服务器的市场账号。管理员也可以允许公开工具免市场登录下载；指定成员工具始终检查发布服务器的成员权限。安装目标工作区仍需登录，因为安装记录、使用数据和文件属于该工作区账号。

市场账号与当前工作区账号独立。市场登录不会替换工作区会话，凭据按「工作区账号 + 市场地址」分别加密保存，切换默认市场不会丢失其他市场的登录。市场会话有效期为 30 天，主动退出、账号失效或密码变更会使其失效。对外服务应使用 HTTPS。

## 从 HTML 文章发布

在工具市场排序右侧点击加号进入独立的「发布工具」页，选择「来源文章」；也可以从文章列表的操作区进入「发布为工具」。文章可以保持私有；发布不会改变原文的可见性。带访问密码的文章不能直接作为工具源。发布设置表单随页面 HTML 一起返回，脚本初始化期间保留完整表单和底部布局，不再等待额外的元数据请求才显示字段。

发布页填写工具名称、简介、分类、版本号、更新说明及安装范围，仅勾选读取工具文件、保存工具文件、TCP 连接三项 BookStark 桥接权限；浏览器联网、设备等已支持能力默认允许，仍受浏览器授权和运行来源限制。「检查资源」会读取并检查实际静态依赖，展示资源数量和预计下载大小，但不会发布，也不保存资源副本。「保存草稿」只保存当前浏览器会话中的发布表单，不改变文章和市场。

发布端只保存工具说明、权限、HTML 版本及原始资源的基准地址，不生成资源压缩包、不复制 JS/CSS/图片等资源。安装时，客户端根据 HTML 中的原始引用递归下载依赖并保存在本地。版本号不可覆盖；修改原文不会自动改变已发布 HTML，但替换同地址的原始资源会影响后续安装，已经安装的副本不受影响。重新打开发布页会保留原权限和描述。市场更新记录展示已批准的版本及说明，不提供客户端回滚入口。

管理员发布后立即上架。普通成员是否可以发布、是否需要管理员审核，由服务器设置决定；需要审核时先保存待审核版本，管理员在市场管理页通过或拒绝。审核使用提交时的 HTML 和发布信息，依赖仍引用原始资源。下架会同时撤回待审核版本，阻止新的安装和下载，保留版本记录和已经安装的副本。

来源文章仍在上架或有待审核版本时，删除会返回 409，并提示先在工具发布页「下架 / 撤回工具」。模型事务和数据库触发器共同保护删除；导入覆盖与回收站永久删除也先检查，避免误清除分享和标签。下架/撤回后才允许删除文章。原始资源仍需保留到不再提供安装为止；直接删除资源会使后续安装失败，但不会影响现有安装。

## 从 ZIP 工具包发布

在同一「发布工具」页选择「上传工具包」，拖拽 ZIP 或选择文件。上传中显示进度并支持取消；上传完成后检查解压后的文件路径、数量、大小与入口页面。检查页可滚动查看完整文件清单、选择 HTML 入口或更换工具包。缺少 HTML 入口会阻止继续；根目录 `tool.json` 可自动填写发布设置，不提供这个文件时也可以手动填写。结构和字段见 [工具包格式](tool-package-format.md)。

工具包不创建占位文章。后端将包内资源保存为独立上传记录，发布时绑定入口、完整文件清单和各文件摘要；安装时下载全部文件并校验大小和摘要，包括没有出现在 HTML 静态引用中的 WASM、Worker、字典和其他动态资源。相对目录保持不变，安装器会调整指向包内资源的根路径引用。

上传工具包后仍进入共用的发布设置页，使用相同的图标、分类、版本、权限、安装范围、审核、下架及客户端安装流程。工具包页面显示文件摘要和「更换工具包」，不显示来源文章。上传只是准备资源，不会立即上架。上传页的「我的工具包」可重新进入已上传工具的发布设置；「保存草稿」仍只保存当前浏览器会话中的表单。

更新时在原工具的发布设置中更换 ZIP，使用新版本号；不会创建另一个工具身份。新包的 `tool.json` 可更新版本和权限，权限变化在发布页提示确认，客户端新增 BookStark 桥接权限仍需手动同意。已经安装的实例、使用数据及工具文件继续保留。包内资源与运行数据分开存储，更换包不会覆盖用户数据。

ZIP 最大 64 MiB，解压后总量最大 256 MiB，单文件最大 64 MiB，最多 256 个文件；HTML 入口发布时另受 20 MiB 上限约束。路径穿越、绝对路径、符号链接和重复文件路径会被拒绝。上传与保存还受工作区 WebDAV 配额约束。失败上传会尝试清理已写入资源；被替换且已无工具或版本引用的上传记录，超过 24 小时后在该账号后续上传时回收。当前可继续发布的上传和已提交的历史版本资源保留。

## 客户端安装和更新

在「广场 → 工具」内使用搜索、分类、安装状态与排序查看工具，支持网格/列表切换及分页，筛选条件保留在页面地址中。工具不再包含子 Tab。工作区管理员点击「设置」弹窗填写默认市场地址，先测试连接，再保存；访客与普通用户不显示设置入口，配置写入和连接测试接口也校验管理员权限。普通登录用户仍可按市场授权安装工具。测试连接不会改动默认设置。原生客户端在设备的 `startup.json` 中保存市场地址和更新偏好；首次可沿用已连接远端工作区的市场地址。从原生客户端进入工具市场会打开设备上的本地工具库，因此工具下载到设备，而不是当前远端工作区。通过普通网页访问时，安装到当前登录的服务器工作区。

市场使用同层广场导航、单一工具列表、工具卡片及详情面板呈现工具。设置弹窗中的市场账号支持登录/退出，账号按输入的市场地址匹配，不替换工作区身份。详情显示版本、大小、资源数量、安装范围及所需 BookStark 桥接权限；卡片和详情不再显示联网或离线标签。确认安装前，如果发布市场要求登录，则单独弹出该市场的登录框；已有工具在切换默认市场后仍从原来的市场获取更新和验证账号。更换市场账号不会顺带更换默认市场地址。

已安装工具与市场工具合并展示，可用「已安装 / 有更新 / 未安装」筛选。卡片提供打开、查看更新及更多操作菜单中的检查更新和卸载。切换来源后，其他市场的已安装工具仍可查看和使用；当前市场暂不可用时也保留已安装工具。默认启动时检查更新并提醒；自动下载更新需要主动开启，新增 BookStark 桥接权限的版本仍需手动确认，浏览器策略字段的变化不会阻止自动更新。更新失败时保持旧安装可用。已安装工具的 HTML、静态依赖和使用数据保存在安装工作区，离线工具不依赖发布端的原始文章或资源。

「打开」进入独立的 `/tools/run/:id` 页面，只显示工具顶部栏和占满剩余空间的 iframe。返回市场恢复原筛选条件和滚动位置；刷新重新加载已安装工具，全屏隐藏顶部栏并提供退出按钮和 Esc。更多菜单提供工具信息、使用数据 JSON 导出，浏览器还支持新标签页打开；小屏把刷新收进更多菜单。旧的 `/market?open=:id` 地址会重定向到独立页。工具页和分享页共用 iframe 尺寸、顶部栏布局样式；工具继续使用安装副本、隔离沙箱和声明的权限。顶部首屏从当前账号的安装记录显示图标及名称；暂未取得身份时仅显示标题位置的小骨架。主内容用工具图标和细环表示正在打开，约 8 秒后仍在等待则提供重新加载、返回入口，不在该时刻中断请求。文档加载完成后立即移除启动提示；工具内部后续异步业务仍由工具自身显示加载状态。加载失败或必需脚本、样式资源无法读取时停止转动并提供重试；减少动效模式显示静态指示。

卸载默认勾选「保留使用数据」，只移除代码和静态资源。再次安装同一工具会恢复结构化数据和用户文件，并创建新的安装实例；旧窗口不能操作新实例。取消勾选则连使用数据、文件一并删除。

## 静态依赖和运行边界

资源下载支持 HTML 图片、srcset、脚本、样式、图标、海报、静态音视频及字幕，递归处理 CSS `url()` / `@import`、JS 字面量模块导入及可识别的 `new URL()`，以及普通 import map。文章依赖检查也识别字面量 WASM 分片路径和 Worker 元数据入口；`new URL('/api/…', …)` 等运行时接口不会当作静态文件下载。文章资源按 URL 去重；工具包使用完整文件清单。内联 data URL 保持内联，重写包内资源后移除失效的 integrity 属性。

HLS/DASH 播放清单和运行时 API 等动态服务不会下载为静态副本。文章中运行时拼接生成的资源地址不能完整地静态推断，需要工具作者明确引用或改用包含完整资源的 ZIP；浏览器联网默认允许，工具是否可离线使用取决于自身依赖和业务。带 scopes 的 import map 或无法安全解析的依赖会明确报错。静态资源无法读取时发布或安装会失败。安装下载失败时保留已有安装及数据，不会生成缺资源的副本。预计大小和资源数量以发布检查时为准，实际下载受原始资源当前内容影响。

单资源上限 64 MiB，全部静态资源上限 256 MiB，最多 256 个资源；安装还受 WebDAV 配额约束。通用依赖下载不携带登录凭据，检查实际连接 IP 及重定向，禁止回环、内网及元数据地址。同服务器的公开上传、公开 WebDAV 资源和 `/static/` 通过本地公开处理器读取。市场地址由用户明确配置，可连接局域网或本机市场。其同源的 `/static/`、`/upload-files/`、`/dav-public/` 公开资源也允许直接下载；其他来源继续使用通用依赖网络限制。禁止链路本地、元数据地址及市场资源重定向，不向资源服务器转发工作区 Cookie 或市场令牌。

跨市场下载会校验 HTML、资源基准地址、版本和权限的清单摘要。文章来源的原始资源字节不包含在该摘要中，也不会冻结，安装时按实际读取内容保存。工具包来源另绑定完整文件路径、大小与文件摘要，安装时逐项验证。跨市场的包资源下载只向明确配置的同源包资源接口发送市场会话，绑定请求的版本和上传记录，并同时检查当前及该历史版本的访问规则；不会把会话转发到任意资源地址或重定向目的地。ZIP 只作为上传格式，版本表不保存压缩包二进制。本地工具在每安装实例独立来源的隔离 iframe 中运行，不能读取宿主登录信息。远端未配置独立来源时保留不带同源权限的 srcdoc；iframe allow、sandbox 和 CSP 使用浏览器能力默认允许的策略，文件和 TCP 消息桥仍按安装版本声明校验。工具资源通过安装专属只读能力地址提供，卸载或更新后旧地址失效，应避免公开转发。工具包在独立来源下按原目录提供文件，专用 Worker 的脚本和网络访问仍受运行环境、CSP 与 CORS 等限制；远端默认的非同源 iframe 使用受限入口适配跨来源的专用 Worker。Service Worker 注册被禁止，不能作为跨版本驻留或缓存安装资源的方式。

## 数据位置和清理

- `md_tools`：独立工具身份、所属账号及可选的来源文章关联；工具包不依赖文章。
- `md_tool_packages`：上传记录、入口候选、完整文件清单、大小及文件摘要。
- `md_tool_releases`：当前已上架版本的目录记录，通过 `tool_id` 关联工具。
- `md_tool_versions`：版本元数据、HTML（`content`）、原资源基准地址（`resource_base`）及审核状态。不存储资源压缩包。
- `md_tool_installs`、`md_tool_install_metadata`：当前账号的安装代码、修订、使用数据及权限。
- `md_tool_market_clients`：当前工作区账号的默认市场与更新偏好。
- `md_tool_market_credentials`：按市场地址隔离、加密保存的市场会话；设备启动偏好不含市场密码。
- `md_tool_retained`：卸载时选择保留的结构化数据及用户文件目录引用。
- 内置 WebDAV `/BookStark/tool-packages/<上传标识>/`：发布端解压后的包资源。
- 内置 WebDAV `/BookStark/tools/<安装实例>/assets/<资源实例>/`：安装版本的静态资源。
- 内置 WebDAV `/BookStark/tools/<数据实例>/data/`：工具产生的用户文件；保留数据重装后可以沿用原数据目录。

升级旧文章工具时迁移原有工具 ID 和版本记录；安装记录、远端市场映射、安装实例及保留数据不重新编号。新文章通过来源关联查找工具，不再假设文章 ID 与工具 ID 永远相同。

本地客户端使用设备上的 SQLite 和内置 WebDAV，具体目录见客户端设置中的数据位置。IndexedDB 不保存工具代码或安装记录。更新先准备完整资源，成功后切换当前安装，再清理旧资源；清理失败持久记录并重试，清理未完成不会假报卸载成功。共享资源按引用计数释放，SQLite 空闲页由后续写入复用。

## HTML 工具数据接口

iframe 的 `localStorage` 通过消息桥异步保存到安装工作区数据库，单工具结构化数据上限 5 MiB。本地客户端保存到设备的本地数据库，远端工作区保存到该工作区的服务器，不会上传到发布市场。工具内部没有写入存储的编辑内容不会自动保存。正常运行时不常驻显示「已保存」；写入失败才显示重试和导出入口。点击返回或刷新会先等待已收到的写入，失败或超时仍有未提交数据时提示确认。具有相应文件权限时，可以读写、列出、查询、删除、重命名、移动和复制自身文件。完整权限列表、文件 API 及 TCP Socket 接口见 [工具权限与桥接 API](tool-permissions.md)。例如：

```js
await BookStark.files.write('exports/report.txt', '报告内容');
await BookStark.files.write('images/result.png', imageBlob);
const bytes = await BookStark.files.read('exports/report.txt');
const text = new TextDecoder().decode(bytes);
```

写入支持字符串、Blob、ArrayBuffer 和 TypedArray，路径不能越出该工具的数据目录。写操作检查修订号和安装实例，数据保存失败时可重试或导出未提交数据。工具仍需自行适配 IndexedDB 和需要外部身份的 API；不能依赖 Service Worker。

## 验证

- `go test ./controllers ./models ./internal/toolpackage -run 'TestTool|TestArchive|TestStaticDependency|TestDependency|TestImportMap|TestMarketPackage|TestRuntimeAPIURL|TestWASMParts'`：文章及工具包发布、审核、独立市场认证、访问规则、远端安装、完整资源清单与摘要校验、文章删除保护、旧工具迁移、资源清理和保留数据。
- `BOOKSTARK_BROWSER_TEST=1 go test . -run '^TestToolMarketBrowser$'`：服务器设置、私有文章发布、安装确认、独立市场登录、切换来源、隔离运行、文件与数据恢复、编辑器入口、多主题双语移动布局。
- `node --test tests/browser/tool_market_worker_test.cjs`：市场与安装数据的缓存及离线请求隔离。
- `go test -tags wails,production,gtk3,purego . -run 'TestClientPreferences|TestNativeClientBridge|TestCredentialVault|TestNativeWorkspaces'`：原生客户端偏好持久化及来源隔离。
