# 工具市场

## 服务器公开市场

管理员在「系统管理 → 工具市场」配置启用状态、名称及对外访问根地址，保存后复制生成的 `https://服务器/market` 地址给客户端。`GET /market/index.json` 提供协议发现；`GET /api/tool-market` 提供目录。关闭市场后停止新的浏览和下载，已经安装的工具仍然可用。

目录默认允许公开浏览，安装默认要求登录发布服务器的市场账号。管理员也可以允许公开工具免市场登录下载；指定成员工具始终检查发布服务器的成员权限。安装目标工作区仍需登录，因为安装记录、使用数据和文件属于该工作区账号。

市场账号与当前工作区账号独立。市场登录不会替换工作区会话，凭据按「工作区账号 + 市场地址」分别加密保存，切换默认市场不会丢失其他市场的登录。市场会话有效期为 30 天，主动退出、账号失效或密码变更会使其失效。对外服务应使用 HTTPS。

## 从 HTML 文章发布

在工具市场点击「发布工具」选择 HTML 文章，或从文章编辑页进入「发布为工具」。文章可以保持私有；发布不会改变原文的可见性。带访问密码的文章不能直接作为工具源。

发布页填写工具名称、简介、分类、版本号、更新说明及安装范围，并声明读取文件、保存结果、访问网络的运行权限。「预览安装包」会检查并打包实际静态依赖，展示资源数量和下载大小，但不会发布。「保存草稿」只保存当前浏览器会话中的发布表单，不改变文章和市场。

发布时将 HTML 及其静态资源保存为固定版本工具包。版本号不可覆盖，再次发布必须使用新版本号。编辑文章或替换原始资源不会改变已发布版本；重新打开发布页会保留原工具的权限和描述。市场中的更新记录展示已批准的版本及说明，不提供客户端回滚入口。

管理员发布后立即上架。普通成员是否可以发布、是否需要管理员审核，由服务器设置决定；需要审核时先保存待审核版本，管理员在市场管理页通过或拒绝。审核使用提交时的固定内容，期间修改文章不会改变待审核包。下架阻止新的安装和下载，保留版本记录和已经安装的副本。

## 客户端安装和更新

在「工具市场 → 市场设置」填入默认市场地址，先测试连接，再保存。测试连接不会改动默认设置。原生客户端在设备的 `startup.json` 中保存市场地址和更新偏好；首次可沿用已连接远端工作区的市场地址。从原生客户端进入工具市场会打开设备上的本地工具库，因此工具下载到设备，而不是当前远端工作区。通过普通网页访问时，安装到当前登录的服务器工作区。

市场使用分类、搜索、工具卡片及详情面板呈现工具。详情显示版本、大小、资源数量、离线能力、安装范围及所需运行权限。确认安装前，如果发布市场要求登录，则单独弹出该市场的登录框；已有工具在切换默认市场后仍从原来的市场获取更新和验证账号。更换市场账号不会顺带更换默认市场地址。

「我的工具」提供打开、检查更新、固定快捷入口及卸载。默认启动时检查更新并提醒；自动下载更新需要主动开启，新增运行权限的版本仍需手动确认。更新失败时保持旧安装可用。已安装工具的 HTML、静态依赖和使用数据保存在安装工作区，离线工具不依赖发布端的原始文章或资源。

卸载默认勾选「保留使用数据」，只移除代码和静态资源。再次安装同一工具会恢复结构化数据和用户文件，并创建新的安装实例；旧窗口不能操作新实例。取消勾选则连使用数据、文件一并删除。

## 静态依赖和运行边界

打包支持 HTML 图片、srcset、脚本、样式、图标、海报、静态音视频及字幕，递归处理 CSS `url()` / `@import`、JS 字面量模块导入及 `new URL()`，以及普通 import map。资源按 URL 去重；内联 data URL 保持内联，重写后移除失效的 integrity 属性。

HLS/DASH 播放清单和运行时 API 等动态服务不会打包。运行时拼接生成的资源地址不能静态推断，需要工具作者明确引用并声明相应联网能力；声明离线工具会限制联网。带 scopes 的 import map 或无法安全解析的依赖会明确报错。静态资源无法读取时发布失败，不会生成缺资源的版本。

单资源上限 64 MiB，全部静态资源上限 256 MiB，最多 256 个资源；安装还受 WebDAV 配额约束。通用依赖下载不携带登录凭据，检查实际连接 IP 及重定向，禁止回环、内网及元数据地址。同服务器的公开上传、公开 WebDAV 资源和 `/static/` 通过本地公开处理器读取。市场地址是用户明确配置的固定协议端点，可连接局域网或本机市场，但禁止链路本地、元数据地址和跨地址重定向，且不转发工作区 Cookie。

跨市场下载会校验版本包摘要、版本及权限信息。工具在没有同源权限的隔离 iframe 中运行，不能读取宿主登录信息；新版本按声明的权限限制网络及文件消息桥。工具资源通过安装专属只读能力地址提供，卸载或更新后旧地址失效，应避免公开转发。

## 数据位置和清理

- `md_tool_releases`：当前已上架版本的目录记录。
- `md_tool_versions`：固定版本元数据、压缩工具包和审核状态。
- `md_tool_installs`、`md_tool_install_metadata`：当前账号的安装代码、修订、使用数据及权限。
- `md_tool_market_clients`：当前工作区账号的默认市场与更新偏好。
- `md_tool_market_credentials`：按市场地址隔离、加密保存的市场会话；设备启动偏好不含市场密码。
- `md_tool_retained`：卸载时选择保留的结构化数据及用户文件目录引用。
- 内置 WebDAV `/BookStark/tools/<安装实例>/assets/<资源实例>/`：安装版本的静态资源。
- 内置 WebDAV `/BookStark/tools/<数据实例>/data/`：工具产生的用户文件；保留数据重装后可以沿用原数据目录。

本地客户端使用设备上的 SQLite 和内置 WebDAV，具体目录见客户端设置中的数据位置。IndexedDB 不保存工具代码或安装记录。更新先准备完整资源，成功后切换当前安装，再清理旧资源；清理失败持久记录并重试，清理未完成不会假报卸载成功。共享资源按引用计数释放，SQLite 空闲页由后续写入复用。

## HTML 工具数据接口

iframe 的 `localStorage` 通过消息桥保存到安装工作区数据库，单工具结构化数据上限 5 MiB。具有相应文件权限时，可以读写自身的 WebDAV 数据目录：

```js
await BookStark.files.write('exports/report.txt', '报告内容');
await BookStark.files.write('images/result.png', imageBlob);
const bytes = await BookStark.files.read('exports/report.txt');
const text = new TextDecoder().decode(bytes);
```

支持字符串、Blob、ArrayBuffer 和 TypedArray，路径不能越出该工具的数据目录。写操作检查修订号和安装实例，数据保存失败时可重试或导出未提交数据。工具仍需自行适配原生 IndexedDB、Service Worker 和需要外部身份的 API。

## 验证

- `go test ./controllers ./internal/toolpackage -run 'TestTool|TestStaticDependency|TestDependency|TestImportMap|TestMarketPackage'`：发布、打包、审核、独立市场认证、访问规则、远端安装、资源生命周期和保留数据。
- `BOOKSTARK_BROWSER_TEST=1 go test . -run '^TestToolMarketBrowser$'`：服务器设置、私有文章发布、安装确认、独立市场登录、切换来源、隔离运行、文件与数据恢复、编辑器入口、多主题双语移动布局。
- `node --test tests/browser/tool_market_worker_test.cjs`：市场与安装数据的缓存及离线请求隔离。
- `go test -tags wails,production,gtk3,purego . -run 'TestClientPreferences|TestNativeClientBridge|TestCredentialVault|TestNativeWorkspaces'`：原生客户端偏好持久化及来源隔离。
