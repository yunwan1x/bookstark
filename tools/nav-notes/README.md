# 星图 · StarDeck

面向 BookStark 工具市场的极简「多环境网址大盘 + 标签随手记」工具包，完全纯前端、零外部 CDN 依赖，支持 PWA 离线运行与工作区同步。

## 核心能力

- **多环境网址大盘**：默认预置「公网 / 内网 / 测试」，支持自由增删自定义环境（如生产、Tailscale、办公室）；普通网站只填默认网址自动兜底，多环境网站支持全局一键切换与单卡临时直开其他环境。
- **网站 Favicon + FontAwesome Hash 智能回退 & 自选图标**：默认优先加载网站真实 Favicon，加载失败或离线时自动按域名 Hash 降级为稳定的 FontAwesome 图标，同时内置 48 款 FontAwesome 图标选择器供手动挑选或随机切换。
- **按设备记忆环境**：电脑端可停留「内网」、手机端可停留「公网」，工作区同步数据时互不覆盖。
- **Flomo 风格标签随手记**：输入 `#服务器`、`#模型`、`#下载`、`#定时任务`、`#临时` 等任意 `#标签` 自动归类；支持左侧按标签筛选、置顶、归档、内联编辑与 `⌘K` 全局检索。
- **路径与命令智能一键复制**：自动识别反引号、代码块以及常见 Linux/Windows 路径、SSH/Docker/Cron 命令行并生成一键复制条。
- **备份与同步**：默认通过 BookStark 工作区 KV 同步并支持离线编辑，同时提供 JSON 导出/导入与工作区文件快照（`backups/nav-notes-snapshot.json`）。

## 打包命令

```bash
python3 source/tools/nav-notes/build.py
```
